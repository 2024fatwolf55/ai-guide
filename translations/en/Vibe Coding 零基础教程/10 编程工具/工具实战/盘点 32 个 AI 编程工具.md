## Mainstream AI Coding Tools

#### Cursor

Let’s start with a nuclear bomb right out of the gate: Cursor is currently the hottest AI coding tool in the world, bar none. The company behind it is valued at nearly $50 billion, making it a true super unicorn in the AI coding space.

I’m a heavy Cursor user. I don’t just have one Ultra account, and I spend tens of thousands of RMB every month on it. About 80% of my project code and daily workflow are now handled through Cursor.

Let me explain why I value Cursor so much. First, its Agent mode is both fast and stable. You can switch between Claude, GPT, Gemini, and all kinds of mainstream models with one click—use whichever you want—and it supports a 100M context window.

Second, the development experience is very good. Plugin management, MCP configuration, model settings, and similar features all have visual interfaces, and you can check Agent status and terminal information at any time.

AI coding ability plus a visual development experience—taken together, it **basically has no rival** among tools of the same category.

![](https://pic.yupi.icu/1/1_cursor.png)

On top of that, Cursor updates very frequently. It already has Cloud Agents for parallel cloud execution, Browser Use for browser-based automated testing, Design Mode for selecting elements directly on the UI and asking AI to modify code, built-in AI image generation, and more. It also provides a command-line version and a web version, so you can open the website on your phone and direct the Agent anytime, anywhere.

However, like most foreign AI coding tools, using it in China comes with some network barriers. The free version can only use the quota provided by Auto mode, and even if you configure your own domestic model, you still can’t use it there.

Also, Cursor is built on the open-source version of VS Code, but the overall interface is not as polished as native VS Code. If the Markdown reading experience were improved a bit, it would be even better.

Let’s look at the price—honestly, it’s not cheap at all. Ultra costs $200 a month, and the bills burn hard. That’s probably one of the reasons many people stop using Cursor.

| Plan | Price |
|:-----|:-----|
| Free | Free (limited Agent and completion quota) |
| Pro | $20/month |
| Pro+ | $60/month |
| Ultra | $200/month |
| Teams | $40/user/month |

Some people also criticize Cursor because it doesn’t have a strong in-house model of its own, and worry that in the future it might get constrained by model providers and lose out to Claude Code or Codex.

No matter what, this tool has completely changed my way of working, and there are almost no problems it can’t solve. If there are, it probably just means I haven’t burned enough tokens yet.



#### GitHub Copilot

Next is the former king: GitHub Copilot.

Copilot comes in a very rich set of product forms, including a VS Code plugin, the GitHub web version, and a command-line terminal version, making it the most widely covered of all the tools. After all, it’s an official Microsoft product, and its integration with VS Code is genuinely excellent. The interface is elegant, and in my opinion the interaction experience is the most comfortable among all tools. Extensions like MCP and Skills can also be managed visually, and the capabilities are very comprehensive.

![](https://pic.yupi.icu/1/2_copilot.png)

I’ve even shown everyone how to build an agent on GitHub Copilot’s web version that can autonomously develop, launch, and fix bugs.

![](https://pic.yupi.icu/1/1774937381654-bde29eb7-3d0f-4869-a065-f7ddb09950dd-20260514180312605.png)

Back in the day, Copilot had amazing cost-performance. You could use an Opus model for just $10 a month, plus it had a 30-day free trial. It really was king status back then. But now the official team can’t keep absorbing the cost forever, so the good days are over and the barrier to use has risen a lot. Starting June 1, it’s also switching to token-based billing, and the context is limited to 200K.

Like other foreign tools, using it in China also comes with network barriers.

| Plan | Price |
|:-----|:-----|
| Free | Free (50 Agent requests + 2000 completions/month) |
| Pro | $10/month |
| Pro+ | $39/month |
| Business | $19/user/month |

The free quota is still enough for light use, and the Pro version at $10/month is not expensive. But do keep in mind that the billing model changed starting in June.



#### Codex

OpenAI’s Codex has been updating at a crazy pace lately. Sam Altman even said it’s going through its ChatGPT moment.

Codex’s interface is all about simplicity. At first glance, it doesn’t even look like an AI coding tool—it looks more like an AI chat assistant. But in reality, it’s very full-featured. MCP extensions, Skills, a plugin marketplace, automation, Git integration, Browser Use, Computer Use—basically all the major engineering capabilities are there. Recently it even added an AI desktop pet for emotional value…

![](https://pic.yupi.icu/1/3_codex.png)

Codex has also pioneered some unique AI coding workflows. For example, it introduced the `/goal` command, which lets you set a persistent goal and have AI work on it autonomously for hours without human intervention.

However, Codex currently **defaults** to using only GPT-family models (though you can quickly switch with tools like CC Switch). GPT-5.5’s coding ability is overall pretty decent and can generally finish a full-stack project in one shot, but its frontend performance is only average, and overall it still falls short of Claude Opus and Cursor using Claude models. And for me personally, GPT-5.5’s 200K-plus input context is genuinely not enough. That’s a fatal flaw!

Codex is also somewhat weaker in ease of use. For example, configuring MCP services still requires writing information manually, unlike Copilot where you can install with one click, and the code reading experience is not as convenient as Cursor, which is built on the VS Code ecosystem.

Like other foreign tools, using it in China requires network tools, and it also requires a ChatGPT subscription.

| Plan     | Price          |
| :------- | :------------ |
| Plus     | $20/month        |
| Pro      | $200/month       |
| Business | token-based |

I personally use the Plus plan. A full-stack project consumes about half of my 5-hour quota, which means I can make roughly 10 complete small projects in a week.

Once it becomes easy for users to freely switch models, reaches a 1M context window, or improves the code reading and writing experience, Codex still has plenty of room to improve.

Let me stress this again: I’m not saying Codex is bad, so please don’t get excited. I’ve written multiple Codex hands-on tutorials and clearly listed all my reasons. I simply hope it can become even better.



#### Windsurf

The strongest impression Windsurf left on me is that it went through acquisition drama involving OpenAI and Google.

If the giants were interested, that means the product itself has substance.

Windsurf’s core Agent is called Cascade. It can autonomously plan and execute multi-step edits across multiple files. After the acquisition, it also integrated Devin, allowing complex tasks to be delegated to the cloud with one click so local and cloud workflows can collaborate in parallel. It also has a Memories feature, where the Agent gradually learns your codebase architecture and coding style, and its suggestions become more accurate over time.

![](https://pic.yupi.icu/1/4_windsurf.png)

Windsurf’s pricing is roughly on par with Cursor. However, compared with Cursor, it still lags in model flexibility and community ecosystem. And in China, it has the same network barriers.

| Plan | Price |
|:-----|:-----|
| Free | Free |
| Pro | $20/month |
| Max | $200/month |
| Teams | $40/user/month |



#### Trae International

Trae is ByteDance’s AI IDE, and it comes in a China edition and an international edition. The differences in models, pricing, and multimodal capabilities between the two are so large that I’m discussing them separately.

The international edition comes with mainstream models like GPT, Gemini, and DeepSeek by default, and it also supports using Claude through your own API Key. Its main feature is SOLO mode, which provides long-term memory and can fully automate development, testing, debugging, and deployment. It also recently launched a mobile app, so you can operate it from your phone.

![](https://pic.yupi.icu/1/5_trae.png)

That said, like other foreign tools, the international edition also has network barriers.

As for pricing, the Pro plan is only $10/month—roughly half the price of Cursor—so its cost-performance is pretty good.

| Plan | Price |
|:-----|:-----|
| Free | Free (basic quota) |
| Lite | $3/month |
| Pro | $10/month |
| Pro+ | $30/month |
| Ultra | $100/month |



#### Kiro

Kiro is an AI IDE released by AWS. What makes it different from other tools is that it focuses on “spec-driven development.”

Put simply, you can’t just ask AI to start writing code right away. Kiro requires you to first describe your requirements in natural language, and then it automatically generates three files: a requirements document, a design document, and a task list. Only after you approve those does it start coding.

It’s a bit like plan mode, but more rigorous. All design intent is version-controlled in the repository, and it also has Agent Hooks—for example, saving a file can automatically trigger tests and documentation updates.

![](https://pic.yupi.icu/1/6_kiro.png)

But for most people just getting started with AI coding, it makes even a small feature change more cumbersome by forcing you through a spec approval flow.

Price-wise, it’s similar to Cursor. Kiro’s default models can be used directly in China and there’s some free quota.

| Plan | Price |
|:-----|:-----|
| Free | Free (50 Credits) |
| Pro | $20/month |
| Pro+ | $40/month |
| Power | $200/month |



#### Zed

Zed is a lightweight AI editor that recently released its official 1.0 version.

Its main selling point is extreme performance. According to the official numbers, cold startup takes only 180 milliseconds, and memory usage is just a bit over 100 MB.

It also has built-in 120fps real-time multiplayer collaborative editing, so multiple people can code simultaneously without installing plugins. On the AI side, it includes an Agent panel and parallel multi-Agent support.

![](https://pic.yupi.icu/1/7_zed.png)

However, its overall maturity still lags behind Cursor, and its extension ecosystem is also much smaller. Honestly, when doing AI coding today, most of the time you’re waiting on AI reasoning and output. A slightly faster editor itself doesn’t feel all that noticeable.

Zed’s Pro plan is priced at $10/month, about half of Cursor’s price, and students can use it for free for a year. Its cost-performance is decent.

| Plan | Price |
|:-----|:-----|
| Personal | Free |
| Pro | $10/month |
| Business | $30/seat/month |



#### Antigravity

Antigravity is Google’s Agent-first IDE. It integrates three work surfaces—the editor, terminal, and built-in browser—and the Agent can autonomously execute tasks across all three. It supports up to 5 Agents in parallel. You only need to approve the results, and the Agent generates screenshots, screen recordings, and code diffs as verifiable deliverables so you can confirm quality. In terms of models, it supports not only Google’s Gemini but also Claude Opus.

![](https://pic.yupi.icu/1/8_antigravity.png)

But since it’s a Google product… well, if you’re in China, you know the drill.

As for pricing, the Pro plan is similar to Cursor, while the Ultra plan at $250/month is even more expensive than Cursor Ultra.

| Plan | Price |
|:-----|:-----|
| Free | Free preview |
| AI Pro | $19.99/month |
| AI Ultra | $250/month |

Since release, Antigravity hasn’t been updating nearly as frequently as Cursor or Codex, and lately its presence feels a bit weaker.



#### Trae China / Qoder / Tencent CodeBuddy

ByteDance’s Trae China edition, Alibaba’s Qoder, and Tencent’s CodeBuddy are basically the three big domestic AI IDEs in China. Their overall functionality is fairly similar, and their biggest shared advantage is **direct access inside China with no network tools required**.

**Trae China edition** differs somewhat from the international version. It switches to domestic models like Doubao Seed Code, DeepSeek, and Kimi, but the core AI coding features are completely free and unlimited (you just have to queue).

![](https://pic.yupi.icu/1/9_trae_cn.png)

**Qoder** is built on its in-house Qwen-Coder model, and the China version also supports third-party model integration. It has a Repo Wiki feature that can automatically generate a knowledge map of a project, making it suitable for understanding large codebases.

![](https://pic.yupi.icu/1/9_qoder.png)

**Tencent CodeBuddy** has a fairly comprehensive product form, including a standalone IDE, VS Code/JetBrains plugins, and a command-line version. Its biggest highlight is deep integration with the WeChat ecosystem, supporting WeChat mini-program development and WeCom bot integration, so it’s particularly suitable for WeChat-related development.

![](https://pic.yupi.icu/1/9_codebuddy.png)

Pricing for the three tools:

| Tool | Free Version | Paid Version |
|:-----|:-------|:-------|
| Trae China edition | Core features free with no limits | Enterprise version from 69 RMB/person/month |
| Qoder | Community free | Pro from $20/month, Teams China region 300 RMB/seat/month |
| CodeBuddy | Free for individuals (limited-time) | Enterprise flagship 198 RMB/person/month |

All three are still evolving rapidly. Functionally, they still lag behind global leaders like Cursor, but they have the huge advantage of direct domestic access, free tiers, and strong Chinese-language experience. For beginners and people with limited budgets, they’re excellent entry points.

I sincerely hope domestic AI coding tools keep improving and catch up with the world’s top tier as soon as possible.



#### OpenCode

OpenCode is an open-source terminal AI coding tool with well over one hundred thousand GitHub stars!

Its biggest advantage is being completely free and open source. It supports a wide range of model providers and includes the Scout Agent for codebase research, making code understanding and navigation convenient. It also released a desktop app and a VS Code extension.

![](https://pic.yupi.icu/1/10_opencode.png)

I tried it back when it first became popular, and my strongest impression was that the frontend UI looked incredibly good. In terms of user experience, it crushed Claude Code. But its backend engineering ability still lagged behind Claude Code.

So here’s the question: if I just want convenient frontend usability, why wouldn’t I use Cursor directly? And if I want the strongest pure coding ability, Claude Code is stronger.

That said, OpenCode does provide some free models, which can be useful for beginners to practice.



#### Warp

Warp is a rather unusual AI terminal tool that recently became open source.

It differs fundamentally from terminal AI coding tools like Claude Code or OpenCode. With those tools, you run an AI program inside your terminal. Warp, on the other hand, is itself a terminal application that adds intelligence to the entire terminal—something like a hybrid of terminal and desktop app.

![](https://pic.yupi.icu/1/11_warp.png)

But after actually using it, I found it a bit awkwardly positioned. If I’m already doing AI coding, I might as well use a full-interface tool like Cursor for higher efficiency. Also, Warp lacks onboarding for new users, so beginners may feel a bit lost at first.

Let’s look at the pricing—not cheap either.

| Plan | Price |
|:-----|:-----|
| Free | Free (150 Credits for first 2 months, then 60 Credits/month) |
| Build | from $18/month |
| Max | from $180/month |
| Business | $45/user/month |

The most annoying part is that I barely used it a few times before my account got banned? Or maybe it was trying to force me to pay? Totally baffling.



#### Goose

Goose is an open-source AI Agent that has already been donated to the Linux Foundation.

It has a Recipes feature that lets you package extensions, prompts, and settings into reusable workflow templates for sharing. Its MCP extension ecosystem is also quite rich, but beyond that, it doesn’t have many standout highlights.

![](https://pic.yupi.icu/1/12_goose.png)

However, Goose is just too low-profile, and its overall ecosystem feels overly niche.



#### Aider

Aider is an open-source terminal AI coding tool with tens of thousands of stars on GitHub.

Its defining trait is deep integration with Git. After it edits code, it can automatically commit and even write the commit description. It also has an Architect mode, where a strong model can plan tasks and a cheaper model can write code, helping save API cost.

But after trying it myself, I found the user experience quite rough. It can even fail at basic tool calling, and it gave me the feeling of AI tools back in 2023 when everything had just started. No wonder its ecosystem remains fairly niche.

![](https://pic.yupi.icu/1/13_aider.png)



#### Claude Code

If Cursor is the king of visual AI coding, then Claude Code is the absolute overlord of command-line AI coding!

Claude Code is Anthropic’s terminal coding Agent, and there’s no question about its ability to handle complex tasks. It’s a rock-solid number one. On the SWE-bench benchmark, it achieved the industry-leading score of 80.8%.

It’s also the leader behind many new AI coding capabilities and conventions. For example, `CLAUDE.md` as a persistent memory file was first introduced in Claude Code, then later standardized across the industry as `AGENTS.md`, with other tools following suit. Mechanisms such as the Hooks event-driven system, Subagents architecture, and Agent Teams multi-Agent collaboration were also first put into practice through Claude Code.

![](https://pic.yupi.icu/1/14_claudecode.png)

By the way, didn’t Claude Code leak its source code to everyone to study not long ago? That’s basically pushing the entire industry forward!

That said, it does have a certain barrier to use. On one hand, it requires command-line knowledge, which isn’t very friendly for people who only know visual interfaces. As a casual example: how do you check the progress of a terminal task in Claude Code? Just let a beginner try figuring that out.

On the other hand, Claude Code uses Anthropic’s own Claude model by default, which cannot be directly used in China. Fortunately, tools like CC Switch can now switch it to domestic models to solve that issue.

Although the interaction experience is less intuitive than visual tools like Copilot, Cursor, or Codex, the command line has its own strengths: flexibility, convenience, and the ability to run in any terminal environment.

If you want the strongest AI coding ability, I still recommend learning some command-line basics. I’ve written many Claude Code hands-on tutorials that everyone can follow.

Now let’s look at pricing. The $20/month Pro plan mainly gives you the Sonnet model, while using the strongest Opus model in Claude Code requires the $100/month Max plan. So yes, it’s still quite expensive.

| Plan | Price |
|:-----|:-----|
| Pro | $20/month (Sonnet 4.6) |
| Max 5x | $100/month (Opus 4.6) |
| Max 20x | $200/month |
| API | pay-as-you-go |

As the absolute benchmark of command-line AI coding, Claude Code is the strongest in AI coding ability and a leader of new paradigms. It’s absolutely worth paying attention to and learning from.

## AI Coding Plugins

Do any of you still use “AI coding plugins” now? I mean the ones installed inside an IDE for code completion and similar tasks.

I personally almost never use them anymore…

There are so many of these plugins, and their features overlap heavily, so I’m going to take a shortcut and group similar ones together.



#### Tongyi Lingma / Baidu Comate / CodeGeeX

Let’s start with the early “three fantasy gods” of domestic AI coding plugins in China: Alibaba’s Tongyi Lingma, Baidu Comate, and Zhipu’s CodeGeeX.

Their core capabilities are all fairly similar: code completion, code explanation, unit test generation, multilingual support, and so on. They can all be accessed directly in China, and the Chinese-language experience is quite good.

![](https://pic.yupi.icu/1/%E9%80%9A%E4%B9%89%E7%81%B5%E7%A0%81.png)

But after 2025, these products didn’t make much noise anymore. In front of tools like Cursor and Claude Code, their presence has become weaker and weaker.



#### Cline

Cline is the benchmark among open-source AI Agent plugins and has more than 60,000 stars on GitHub.

Compared with the three domestic plugins above, Cline’s biggest advantage is stronger Agent capability. It supports both Plan and Act modes, as well as a Checkpoints rollback mechanism, so if things get messed up, you can revert to a previous state with one click.

![](https://pic.yupi.icu/1/cline.png)

Cline has millions of installs in the VS Code marketplace, enjoys a solid reputation among developers worldwide, and has stayed active in the community.



#### Kilo Code / JetBrains Junie / Continue / Augment Code

Next are some AI coding plugins with relatively low overall visibility. I suspect many of you haven’t even heard of them, so I’ll group them together.

**JetBrains Junie** is JetBrains’ own AI Agent. It can take over tasks completely and execute them autonomously, and it uses the IDE’s syntax tree for compiler-level error correction. But it only supports JetBrains IDEs, not VS Code, and you need to change your account region to use it.

![](https://pic.yupi.icu/1/junie.png)

**Kilo Code** is essentially a fork of Cline that took a commercial path. It supports many models and platforms, covering VS Code, JetBrains, CLI, mobile, and more, and also includes a Memory Bank feature for persistent project context.

**Continue** offers a lot of model flexibility, but its configuration is indeed rather complex, so the barrier to entry is higher.

**Augment Code** brands itself as an expert for large codebases, and its Context Engine can index huge numbers of files. But it has already begun regional blocking, making registration difficult in China, and it’s not cheap either.

Although each of these plugins has its own characteristics, their overall presence in today’s AI coding plugin space is relatively weak, and it’s hard for them to compete with mainstream AI IDEs on features.



#### Tabnine

If I remember correctly, Tabnine was a very popular code completion plugin back when I was in college. But now it has completely shifted toward the enterprise market. The free version is gone, the personal paid version is being removed, and only enterprise plans remain. Ordinary developers basically can’t use it anymore.

![](https://pic.yupi.icu/1/tabnine.png)



## AI Low-Code Platforms

Next are AI low-code platforms. These platforms basically all look similar. In simple terms, you enter one prompt, and they help you generate a complete application and even deploy it online automatically.

The most important thing about this category is convenience. The frontend needs to look good, the backend needs to be stable, and generation speed needs to be fast.

To keep the comparison fair, I used free accounts for all of them and tested them all with the same prompt: completely imitate Yupi AI Navigation and build a food-navigation website.

This task requires searching my website online, so it tests both Agent capability and frontend fidelity.

Now let’s go through how each AI low-code platform performed.



#### Manus

Manus took the longest—about 15 minutes—but **its fidelity was the highest**. It captured my site’s style very accurately.

![](https://pic.yupi.icu/1/manus.png)

My previous impression of Manus actually wasn’t great, because once when I used it in a video demo for everyone, I got roasted pretty badly…

People think Manus’s story is even more dramatic than its product: explosive popularity, funding, layoffs, fleeing to Singapore, being acquired by Meta for more than 2 billion, then being halted by China’s National Development and Reform Commission. It’s practically a long-running TV drama—too dramatic even for AI to invent.

But unexpectedly, in this round of testing, Manus actually performed the best. Manus mainly excels at frontend generation and automated deployment, while its backend ability is relatively limited. It’s more suitable for showcase apps and MVP prototypes.

Its pricing starts from $20/month.



#### v0.dev / Lovable / Replit Agent

**v0.dev** is made by Vercel, the company behind the famous frontend framework Next.js. It completed the task in 3 minutes and 57 seconds and **also reproduced my site’s style** very well.

It’s still strongest at frontend UI generation. Although the official product already supports some backend logic through Next.js Server Actions and API Routes, the actual backend code quality it generates still isn’t great, so it’s good for prototyping but not ideal for direct production use.

![](https://pic.yupi.icu/1/v0dev.png)

**Lovable** was the fastest, finishing in just 3 minutes and 8 seconds, but **it did not reproduce my site’s style**. It’s better at generating MVPs from scratch, and it is deeply integrated with Supabase for auth and database features, plus Stripe payment scaffolding, which makes it more beginner-friendly for non-technical users.

![](https://pic.yupi.icu/1/lovable.png)

**Replit Agent** took 6 minutes and **also failed to reproduce my site’s style**. Compared with the other two, it doesn’t really have any especially unique features.

![](https://pic.yupi.icu/1/replit.png)

The pricing of these platforms is all roughly similar:

| Platform | Free Version | Paid Version |
|:-----|:-------|:-------|
| v0.dev | Free ($5 monthly credits) | Premium $20/month |
| Lovable | Free (30 credits/month) | Pro $25/month |
| Replit Agent | Free available | Core $20/month, Pro $100/month |



#### Bolt.new

In my free AI coding tutorial, I use Bolt.new as the beginner demo tool for non-programmers to start building AI applications.

But in this test, it crashed and burned… It overcomplicated the requirement, jumped straight into Plan mode, burned through all the tokens on my free account, and still didn’t write a single line of code.

![](https://pic.yupi.icu/1/boltnew.png)

Come on! How are beginners supposed to use that?

Overall, this category of AI low-code platform is more suitable for complete beginners to get started quickly. But if you’re after more flexible and more powerful AI coding ability, you should still use the mainstream AI coding tools I mentioned at the beginning.



## AI Agents

Finally, let’s talk about AI Agent-style products.

An AI Agent is an intelligent assistant that can autonomously complete complex tasks. You give it a goal, and it breaks the task down, calls tools, and executes it step by step.

Although the following products aren’t professional AI coding tools in the strict sense, they can also be used for AI coding, so I’m including them here to broaden everyone’s horizons.

#### OpenClaw / Hermes Agent

OpenClaw is an open-source all-purpose AI assistant. Its biggest strength is that it can connect to all kinds of platforms such as WeChat, DingTalk, and Feishu, so you can assign tasks to AI anytime, anywhere. It’s genuinely very convenient for building demos.

![](https://pic.yupi.icu/1/openclaw.png)

When it first exploded in popularity, I published a whole series of tutorials for everyone—from beginner-friendly installation to advanced use cases to real project practice.

![](https://pic.yupi.icu/1/OpenClaw%E6%95%99%E7%A8%8B%E6%BC%94%E7%A4%BA-%E6%8A%80%E8%83%BD%E7%B3%BB%E7%BB%9F.png)

Hermes Agent is also one of the most popular Agent products right now and belongs to the same category as OpenClaw. But the biggest difference is that it has **self-evolution capability**. After solving a problem, it can automatically generate reusable Skills, making it smarter over time.

![](https://pic.yupi.icu/1/hermes.jpg)

I’ve personally used them to build some demos, and I can only say they’re “usable.” But if you want to do a serious real project, their stability is far behind professional AI coding tools. For a complete project, you’ll probably still end up handing things over to Cursor or Claude Code. And the token burn is brutal! Ordinary people either don’t know how to use them, or simply can’t afford to.



## Final Thoughts

To sum it up: if you’re just getting started with AI coding, I recommend **Trae China edition** for zero-cost practice. For more advanced real-world development, use **Cursor**. And if you want to go deeper, learn the command-line workflow of **Claude Code**. Also, Codex is absolutely worth paying attention to. If it eventually supports fully free model switching, who knows—maybe it could even surpass Claude Code.

Overall, AI coding ability = model + engineering. Domestic tools are rapidly shrinking the gap on the engineering side. Whatever new capability appears in foreign tools, domestic products often follow quickly. But there’s still a gap in the underlying reasoning ability of the base models. I’m really looking forward to domestic AI pushing prices down so more people can afford to use it.

Once you understand all this, you’ll be able to choose the AI coding tool that best fits your needs and budget.
