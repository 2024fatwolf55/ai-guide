# Model Updates

> The latest AI model releases, evaluations, and industry news



Hello, I'm Yupi.

AI models are updating faster and faster now. Every few weeks, a new model comes out, and it's honestly dizzying.

This section is dedicated to recording important model releases and hands-on comparisons, helping you quickly understand the capability boundaries of new models and make better choices.

The current content falls into two categories. One is in-depth testing of individual models. For example, DeepSeek V4 Pro, Claude Opus 5, and Kimi K3 were all tested with the same set of prompts across 7 projects for easier side-by-side comparison; Xiaomi MiMo used 4 project cases. The other category is head-to-head comparisons, such as the three-model GLM-5.3 comparison (GLM-5.3, Kimi K3, and DeepSeek V4 Pro tested in the unified DeepSeek Harness environment), the GPT-5.6 three-model comparison, the Opus 4.8 four-model comparison, and Claude Fable 5 versus Opus 4.8 and GPT-5.5. In all of these, several models are asked to build the same project with the exact same prompt, so you can directly see whose completion quality is higher.

The content here is more like “news + reviews,” so you don’t need to study it in order. Just drop by whenever a new model is released. If you want a systematic understanding of how to choose AI models, I recommend reading *AI Model Selection Guide* in the Programming Tools section of this tutorial first.
