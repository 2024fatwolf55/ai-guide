# Project Deployment Tutorial

Hello, I'm Programmer Yupi.

In previous articles, we learned how to develop various projects. However, if a project can only run locally, it would be a pity. In this article, I will teach you how to deploy a project to the internet, making it accessible to people worldwide.

First, it's important to note that if you're using AI zero-code platforms like Bolt.new, Lovable, Meituan NoCode, or Baidu Miaoda, they usually come with built-in deployment features. You can simply click the publish button to go live, which is very convenient. However, if you want more flexible deployment options, such as using your own domain, choosing different servers, or deploying more complex full-stack projects, you'll need to learn more deployment methods.

Below, I'll introduce multiple deployment methods, from the latest AI auto-deployment to the popular Vercel one-click deployment, and even professional server deployment. You can choose the appropriate deployment method based on your project type and needs.

## Overview of Deployment Methods

Before we start, let's take a look at the available deployment methods.

For frontend projects (static websites, single-page applications, etc.), the simplest way is to use hosting platforms like Vercel, GitHub Pages, EdgeOne Pages, etc. These platforms offer free hosting services. You just need to upload your code, and they will automatically deploy it and generate an access link.

For full-stack projects (including both frontend and backend), you can choose containerized deployment (Docker), cloud server deployment (Alibaba Cloud, Tencent Cloud, etc.), or Serverless deployment. These methods are relatively more complex but offer more powerful features.

Below, I'll detail each deployment method.


Make sure to replace the API Token with your own and delete the comments, otherwise, it will cause errors:

This service provides two tools:

- deploy_html: Deploys HTML content to EdgeOne Pages and returns a public access URL
- deploy_folder_or_zip: Deploys a folder or ZIP file to EdgeOne Pages and returns a public access URL

## Vercel One-Click Deployment (Recommended)

[Vercel](https://vercel.com) is currently the most popular frontend deployment platform, especially suitable for React, Next.js, Vue, static websites, and other frontend projects.

The advantages of Vercel are that personal projects are completely free, deployment speed is extremely fast (usually 1 ~ 2 minutes), automatic HTTPS and CDN acceleration are configured; it also integrates deeply with GitHub, automatically deploying when you push code to a GitHub repository.

### Usage Steps

1) First, visit the [Vercel official website](https://vercel.com) to register an account. It's recommended to use a GitHub account to register and log in.

2) Create a project, directly bind GitHub and select an already hosted project, then click the "Deploy" button:

![](https://pic.yupi.icu/1/image-20260109111323983.png)

3) Wait for 1 ~ 2 minutes, and the project is live!

After successful deployment, Vercel will automatically give you a domain, such as `your-project.vercel.app`. You can also bind your own domain. Moreover, every time you push code to GitHub, Vercel will automatically redeploy, requiring no manual operation.

## Cloud Server Deployment

If you want more control, you can rent a cloud server and deploy the project yourself. Mainstream cloud service providers in China include Alibaba Cloud, Tencent Cloud, and Huawei Cloud.

The basic process of cloud server deployment:

1) Purchase a cloud server (recommended starting with a 2-core 4GB configuration, with new user discounts for first-time purchases)

2) Install the runtime environment, such as Node.js, Nginx, MySQL database, etc.

3) Upload code to the server

4) Configure Nginx reverse proxy

5) Configure domain and SSL certificate

This process can be a bit complex for pure beginners, but you can use visual management tools like BT Panel or 1Panel to greatly simplify operations. These panels provide a graphical interface, eliminating the need to remember complex commands, and you can complete configurations with just a few clicks.

![](https://pic.yupi.icu/1/1736821032080-4be9c9e5-6dfe-434b-8db8-7eb8d7068a16.png)

The advantage of cloud server deployment is that you have full control. You can adjust the configuration at any time, and it's also more stable. The downside is that it requires a certain amount of programming or operations knowledge, and the server itself costs money (usually anywhere from dozens to hundreds of yuan per month).

## Docker Containerized Deployment

For full-stack projects that include both a frontend and a backend, Docker is an excellent deployment method. Docker can package your application together with its runtime environment into a container, which can run on any server that supports Docker.

Docker's advantage is excellent environment consistency. You won't run into the classic problem of "it works on my computer, but it doesn't work on the server." It's also very convenient for managing multiple applications—each app runs independently without affecting the others.

The basic process of deploying with Docker is:

1. Write a `Dockerfile` to define the application's runtime environment
2. Build a Docker image
3. Run a Docker container
4. Configure Nginx reverse proxy (if needed)

This process is relatively more complex, but AI can help you complete it. You just need to tell AI: "Help me write a Dockerfile for deploying this Node.js project." AI will generate the complete Dockerfile and deployment scripts for you.

If you want to learn enterprise-level deployment methods, I recommend studying Docker in depth.

## CDN Acceleration Optimization (Optional)

After deployment is complete, if you want your website to load even faster, you can also use CDN acceleration.

A CDN (Content Delivery Network) caches your website's content on servers around the world, and when users visit, it automatically chooses the server closest to them, greatly improving loading speed.

![](https://pic.yupi.icu/1/1763643073516-5248d56c-bf7d-4537-b8f8-681a104626d9.png)

[Cloudflare](https://www.cloudflare.com/zh-cn/) provides free CDN services, with advantages such as:

- Completely free (for personal websites)
- Global CDN acceleration covering 200+ cities
- Automatic HTTPS certificates
- DDoS protection and web firewall
- Free DNS service

It's very easy to use: register a Cloudflare account, add your domain, and then change your domain's DNS servers to the addresses Cloudflare provides. Cloudflare will automatically accelerate and protect your website.

You can also directly use the Cloudflare Pages deployment feature: upload your code, let it deploy with one click, and even claim a free domain from it—super convenient~

![](https://pic.yupi.icu/1/1763643412558-4d499b46-5e16-4f83-9df7-06a85175df35.png)

If your website is deployed on Vercel or Netlify, they already come with CDN acceleration built in, so you don't need to configure Cloudflare separately. But if you're renting and deploying on your own server, I strongly recommend using Cloudflare for acceleration.

## Domains and SSL Certificates

After deployment, you may want to configure an easy-to-remember domain for your website instead of making users visit a hard-to-remember IP address forever.

### Buying a Domain

A domain is the address of a website, such as [codefather.cn](https://codefather.cn/) or [dogyupi.com](http://dogyupi.com/). For users in China, I recommend buying domains from well-known cloud providers such as [Alibaba Cloud](https://wanwang.aliyun.com/) or [Tencent Cloud](https://dnspod.cloud.tencent.com/). The price is usually only dozens of yuan per year, and the interfaces are all in Chinese, which makes the process very convenient.

One thing to note: if your website server is located in mainland China, the domain needs ICP filing. The filing process generally takes 1-2 weeks and requires identity card, phone number, and other information. If your website is deployed on overseas platforms such as Vercel or Netlify, or if the domain is purchased on an overseas platform, then you can skip the filing process and launch much faster.

### Configuring an SSL Certificate

Nowadays, websites basically all require HTTPS, so you need to configure an SSL certificate. The good news is that most deployment platforms configure SSL certificates automatically, so you don't need to do it manually.

For example, Vercel, Netlify, GitHub Pages, and EdgeOne Pages will all automatically configure HTTPS for you. You only need to bind your domain.

If you're deploying on a server you rent yourself, you can use a free certificate from [Let's Encrypt](https://letsencrypt.org/zh-cn/), or use Cloudflare's CDN, both of which will automatically configure HTTPS.
