# Cursor + LangChain4j - AI Programmer Training Ground Project in Action

This project is an AI programmer training ground that helps developers improve their technical skills through gamification. Users choose a technical direction and difficulty level, the AI automatically generates challenge tasks, and users earn rewards and experience points after completing the challenges.

This is a full-stack project built mainly with Vibe Coding. The entire development process uses AI, and both the frontend and backend can be generated with tools like Cursor. The focus is on learning how to use AI to generate a complete full-stack project, making it a great fit for anyone who wants to learn AI app development or build their own product.

Estimated learning time: 6–12 hours.

Project code is open source for free: https://github.com/liyupi/coder-test

Project text + video tutorial: https://www.codefather.cn/course/1965699176489484289
