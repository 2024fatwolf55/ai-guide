## 一、Git 版本管理

### 為什麼需要 Git？

在開發過程中，你可能會遇到這些情況：

- 剛才改了程式碼，結果改壞了，想恢復到之前的版本
- 想嘗試一個新功能，但又怕影響現有的程式碼
- 多人協作時，不知道誰改了什麼

這些問題，Git 都能幫你解決。

**Git 是一個版本控制工具**，可以記錄程式碼的每一次修改，隨時回退到任何歷史版本。

💡 如果你想成為一名專業的程式設計師，那麼必學 Git，這是企業開發的基本功。



### Git 的核心概念

Git 的工作流程很簡單，主要就三步：

1. 在工作區修改程式碼
2. 新增程式碼到暫存區（用 `git add` 命令）
3. 提交程式碼到倉庫（用 `git commit` 命令）

打個比方，修改程式碼就像在草稿紙上寫東西，新增到暫存區就像把滿意的內容挑出來，提交到倉庫就像把這些內容正式儲存到筆記本里。

![](https://pic.yupi.icu/1/gitworkflow%E5%A4%A7.jpeg)



### 怎麼使用 Git？

有 2 種使用 Git 的方式：**視覺化工具** 和 **命令列**。

對於新手來說，我強烈推薦先用視覺化工具。現在很多主流的開發工具（比如 Cursor、VS Code）都內建了 Git 功能，點幾下滑鼠就能完成程式碼的提交和拉取，完全不需要記命令。

我自己剛開始接觸 Git 的時候就是這樣，完全沒有上網搜教程，就是看別人提交專案的時候在編輯器上點幾下就搞定了，覺得很神奇。然後我就有樣學樣地用起了這個工具。而且很長一段時間我都是用 [GitHub Desktop](https://desktop.github.com/) 來傻瓜式操作，遇到問題了再上網搜解決方案。

![GitHub Desktop APP](https://pic.yupi.icu/1/screenshot-windows-dark.png)

等你熟練了之後，可以再學習命令列操作。命令列雖然看起來複雜，但其實更靈活、更強大，而且很多高階功能只能透過命令列實現。

下面是幾個最常用的命令，學會這幾個命令，就能應付 90% 的日常開發了。

```bash
# 克隆專案
git clone https://github.com/liyupi/ai-guide.git

# 檢視狀態
git status

# 新增檔案
git add .

# 提交
git commit -m "新增了新功能"

# 推送到遠端
git push

# 拉取最新程式碼
git pull
```

不用刻意去背，用到的時候查一下就行，或者直接問 AI。

這裡我建議大家無論是否要學習 Git，都可以先把它安裝到你的電腦中，[直接去官網安裝](https://git-scm.com/) 就好。有可能一些軟體或工具會依賴 Git，不裝的話後面會出現一些問題。



### 實際使用場景

讓我用一個實際例子來演示 Git 的用法。比如你用 Cursor 做了一個專案，想用 Git 管理版本。

1）首先在專案的根目錄中執行命令來初始化 Git：

```bash
git init
```

2）然後新增所有檔案並提交第一個版本：

```bash
git add .
git commit -m "初始版本"
```

3）接下來繼續開發，修改了一些程式碼。修改完成後再次提交：

```bash
git add .
git commit -m "新增了使用者登入功能"
```

4）如果某次修改出了問題，想回退到之前的版本，可以這樣：

```bash
git log  # 檢視歷史，找到想回退的版本號
git reset --hard 版本號
```

Git 會幫你記錄每一次修改，隨時可以回退。



### Git 和 AI 工具的配合

現在很多 AI 工具都內建了 Git 功能。比如 Cursor 可以在編輯器裡直接提交程式碼：

![](https://pic.yupi.icu/1/image-20260109110826513.png)

也可以讓 AI 幫你自動執行 Git 命令，就跟它說 “幫我用 Git 來管理專案” 就可以了。

此外，AI 還能幫你生成提交資訊，一切皆可 Vibe Coding！

我建議大家養成一個習慣：**每完成一個功能，就提交一次**。

這樣即使 AI 改壞了程式碼，也能隨時恢復到之前的版本。有了 Git，你就可以放心大膽地讓 AI 改程式碼了，反正隨時能回退。



### 學習建議

Git 的功能很強大，但對於 Vibe Coding 來說，掌握上面這些用法就夠用了。如果想深入學習 Git 和 GitHub，可以看看魚皮寫的 [Git & GitHub 學習路線](https://www.codefather.cn/course/1789189862986850306/section/1789190804671012866)。這個學習路線從零基礎到精通，涵蓋了 Git 的所有核心知識點，而且完全免費。



## 二、部署託管平臺

你用 AI 做好了專案，雖然在本地執行得很好，但如果想讓別人也能訪問，就需要把專案部署到伺服器上。

傳統的部署方式很複雜：要租伺服器、配置環境、上傳程式碼、配置域名等等。但現在有很多免費的部署平臺，可以讓你幾分鐘就把專案上線。



### Vercel

[Vercel](https://vercel.com) 是目前最流行的前端部署平臺，特別適合 React、Next.js、Vue、靜態網站等前端專案。

優點是個人專案完全免費，部署速度極快（一般 1 ~ 2 分鐘），自動配置 HTTPS 和 CDN 加速；還和 GitHub 深度整合，能夠在你推送程式碼後自動部署。

使用 Vercel 超級簡單。

1）首先訪問 [Vercel 官網](https://vercel.com) 註冊賬號，建議使用 GitHub 賬號註冊登入。

2）建立專案，可以直接繫結 GitHub 並選擇已經託管的專案，點選 "Deploy" 部署按鈕：

![](https://pic.yupi.icu/1/image-20260109111323983.png)

3）等待 1 ~ 2 分鐘，專案就上線了！

部署成功後 Vercel 會自動給你一個域名，比如 `your-project.vercel.app`，你也可以繫結自己的域名。

而且每次你往 GitHub 推送程式碼，Vercel 都會自動重新部署，完全不用手動操作。

💡 具體過程可以看魚皮的影片教程：https://www.bilibili.com/video/BV1TV4y1j76t



### Netlify

[Netlify](https://www.netlify.com/) 和 Vercel 類似，但功能更全面一些。支援更多的框架和靜態站點生成器，有表單處理、無伺服器函式等功能，免費額度更大、還支援 A/B 測試和分析。使用方式和 Vercel 類似，不過多介紹了。



### EdgeOne Pages 國產部署平臺

[EdgeOne Pages](https://pages.edgeone.ai) 是騰訊雲推出的邊緣全棧開發平臺，它基於騰訊雲 EdgeOne 基礎設施，提供從前端頁面到動態 API 的無伺服器部署體驗。


EdgeOne 是騰訊雲的邊緣安全加速平臺，簡單來說就是 “網路加速 + 安全防護” 的組合。它利用騰訊遍佈全球的網路節點，讓你的網站在離使用者更近的地方提供服務，載入速度更快。同時還整合了 Web 防護能力，可以在邊緣就過濾攔截惡意流量，保護你的網站安全。

EdgeOne Pages 基於這個強大的基礎設施，優點是國內訪問速度快，和騰訊雲服務深度整合，支援邊緣函式，有免費額度。更適合國產開發者寶寶們~



### GitHub Pages

[GitHub Pages](https://pages.github.com/) 是 GitHub 提供的免費靜態網站託管服務。優點是完全免費、無限流量、和 GitHub 無縫整合。

使用方法巨簡單，在 GitHub 建立倉庫並上傳網站檔案後，直接在倉庫設定中啟用 GitHub Pages：

![](https://pic.yupi.icu/1/image-20260109111917547.png)

然後就能透過 `username.github.io/repo-name` 訪問了。適合個人主頁、專案文件、簡單的靜態網站。



### 如何選擇？

- 如果你的專案是 Next.js，選 Vercel（官方推薦）
- 如果是其他前端框架或靜態網站，Vercel 和 Netlify 都可以
- 如果是國內使用者，想要更快的訪問速度，選 EdgeOne Pages
- 如果只是簡單的靜態頁面，GitHub Pages 最簡單

我自己主要用 Vercel + EdgeOne Pages，因為它速度快、體驗好。國內專案會用 EdgeOne Pages，訪問速度確實快很多。



### Cloudflare CDN

如果你想讓網站訪問速度更快，還可以使用 [Cloudflare](https://www.cloudflare.com/zh-cn/) 的免費 CDN 服務。

CDN（內容分發網路）就是把你的網站內容快取到全球各地的伺服器上，使用者訪問時會自動選擇離他最近的伺服器，大大提高載入速度。

![](https://pic.yupi.icu/1/1763643073516-5248d56c-bf7d-4537-b8f8-681a104626d9.png)

Cloudflare 的優勢是：

- 完全免費（個人網站）
- 全球 CDN 加速，覆蓋 200+ 個城市
- 自動 HTTPS 證書
- DDoS 防護和 Web 防火牆
- 免費的 DNS 服務

使用方法很簡單，註冊 Cloudflare 賬號，新增你的域名，然後把域名的 DNS 伺服器改成 Cloudflare 提供的地址就行。Cloudflare 會自動幫你加速和保護網站。

也可以直接使用 Cloudflare 提供的 Pages 頁面部署能力，直接上傳自己的程式碼，交給它一鍵部署並白票免費的域名，更方便~

![](https://pic.yupi.icu/1/1763643412558-4d499b46-5e16-4f83-9df7-06a85175df35.png)

如果你的網站部署在 Vercel 或 Netlify 上，它們本身就有 CDN 加速，不需要額外配置 Cloudflare。但如果你是自己租伺服器部署，強烈建議用 Cloudflare 加速。

## 三、MCP 服務 - 擴充套件 AI 能力

MCP（Model Context Protocol） 是一個開放標準，可以讓 AI 工具連線到各種外部工具和資料來源。

簡單來說，MCP 就像給 AI 裝上了各種 "外掛"，讓它能做更多事情。比如檔案系統 MCP 讓 AI 可以讀寫檔案，GitHub MCP 讓 AI 可以操作 GitHub 倉庫，資料庫 MCP 讓 AI 可以查詢資料庫，瀏覽器 MCP 讓 AI 可以瀏覽網頁。

![](https://pic.yupi.icu/1/mcp.png)

現在幾乎所有主流 AI 程式設計工具都支援 MCP，包括 Cursor、Claude Code、Cline、Windsurf、Gemini CLI、Kiro 等。你可以在這些工具中使用各種 MCP 服務，大大擴充套件 AI 的能力。

下面我用 Cursor 作為例子，演示如何配置和使用 MCP。



### 在 Cursor 中使用 MCP

讓我用一個實際例子來演示如何在 Cursor 中配置和使用 MCP。

比如我希望讓 Cursor 能夠得知當前準確的時間。

1）利用 MCP 大全網站搜尋你需要的 MCP 工具，並獲取到 MCP 配置資訊，後面會用到：

![](https://pic.yupi.icu/1/image-20260109113038258.png)

由於這個 MCP 工具需要用到 `uvx` 命令來安裝，我們需要先安裝 uv 工具。參考 [官方安裝文件](https://docs.astral.sh/uv/getting-started/installation/)，選擇作業系統並執行一行命令，就能完成安裝了。

![](https://pic.yupi.icu/1/image-20260109113308798.png)

安裝後，執行 `uvx` 命令，應該會看到下圖的輸出，表示安裝成功：

![](https://pic.yupi.icu/1/image-20260109113427041.png)



2）開啟 Cursor 設定，找到 MCP 配置選項，點選新增 MCP：

![](https://pic.yupi.icu/1/image-20260109113809834.png)



3）Cursor 是透過 JSON 檔案來管理 MCP 的，新增前面複製的 MCP 伺服器配置：

```json
{
  "mcpServers": {
    "time": {
      "command": "uvx",
      "args": [
        "mcp-server-time",
        "--local-timezone=America/New_York"
      ]
    }
  }
}
```

![](https://pic.yupi.icu/1/image-20260109112647904.png)



4）儲存後，會發現 MCP 工具已成功開啟，現在 AI 就可以獲取到最新時間了。

![](https://pic.yupi.icu/1/image-20260109113524465.png)



5）你可以問 AI：現在幾點鐘？

AI 就能透過呼叫 MCP，給你最準確的時間。

![](https://pic.yupi.icu/1/image-20260109113631840.png)

## 五、其他實用工具

除了上面這些工具，還有一些其他實用工具值得了解。



### GitHub 程式碼託管

[GitHub](https://github.com/liyupi) 是全球最大的程式碼託管平臺，不僅可以託管程式碼，還能和全球優秀的開發者交流 ♂。

你可以在 GitHub 上託管程式碼、展示專案、學習別人的程式碼、參與開源專案。而且很多 AI 工具都支援和 GitHub 整合，比如 Cursor、Vercel、Netlify 等。

![魚皮 GitHub 的專案倉庫](https://pic.yupi.icu/1/image-20251126231252956.png)

個人建議，給自己的每個專案都建立一個 GitHub 倉庫，既能備份程式碼，又能展示作品。



### 圖床工具

如果你的專案需要圖片，就會遇到一個問題：圖片放哪裡？

直接放在專案裡會讓專案變得很大，而且如果把圖片檔案放到自己的小水管伺服器上，載入速度會比較慢。這時候就需要用到圖床工具了。

**圖床工具就是專門用來儲存和管理圖片的服務**，你把圖片上傳上去，它會給你一個連結，你在專案裡用這個連結就行。

圖床工具分兩種：**線上圖床 **和 **本地圖床工具**。

線上圖床就是直接在網頁上傳圖片，比如 [imgchr](https://imgchr.com/)，優點是簡單方便，缺點是可能不太穩定。

我更推薦用 [PicGo](https://molunerfinn.com/PicGo/)，這是一個本地圖床工具，支援多種圖床平臺（GitHub、七牛雲、騰訊雲、阿里雲等）。你可以在本地管理圖片，上傳後自動複製連結，非常方便。

![](https://pic.yupi.icu/1/image-20260109114343606.png)

而且 PicGo 還支援快捷鍵上傳、截圖上傳等功能，用起來特別順手。如果你經常需要在文章或專案裡插入圖片，強烈推薦試試 PicGo。

魚皮寫文章一般是用 Typora 寫作工具 + PicGo 上傳圖片，可以保證自己文章中的圖片在任意電腦上都能訪問。



### 環境變數管理

在專案中，你經常會用到一些敏感資訊，比如 API Key、資料庫密碼等。千萬不要直接寫在程式碼裡！不然別人一看你的程式碼，這些金鑰就洩露了。

正確的做法是使用環境變數。在本地開發時，建立一個 `.env` 檔案：

```
OPENAI_API_KEY=your_key_here
DATABASE_URL=your_database_url
```

然後在程式碼裡透過 `process.env.OPENAI_API_KEY` 這樣的方式來讀取。

部署到 Vercel 或 Netlify 時，在它們的設定頁面新增環境變數就行，不用把 `.env` 檔案上傳上去。這樣既安全，又方便管理。



### 域名服務

簡單來說，域名就是網站的地址。比如 `codefather.cn`、`dogyupi.com`。

如果你想讓自己的專案有一個好記的網址，就需要購買一個域名，而不是直接讓使用者透過 IP 訪問。

對於國內使用者，我推薦在 [阿里雲](https://wanwang.aliyun.com/) 或 [騰訊雲](https://dnspod.cloud.tencent.com/) 這種知名雲服務商購買域名。價格一般是幾十塊錢一年，而且操作介面都是中文的，很方便。

![](https://pic.yupi.icu/1/image-20260109114615834.png)

需要注意的是，**如果你的網站伺服器在國內，域名需要備案**。備案流程大概需要 1 ~ 2 周，需要提供身份證、手機號等資訊。

如果你的網站部署在 Vercel、Netlify 這些國外平臺上，或者在國外平臺購買域名，那麼可以省去備案，快速上線。



### 資料庫服務

資料庫就是用來儲存資料的地方。

比如你做一個待辦事項應用，使用者新增的待辦事項就需要存到資料庫裡；你做一個部落格網站，文章內容也需要存到資料庫裡。

對於 Vibe Coding 開發者來說，我強烈推薦 [Supabase](https://supabase.com/)。它是一個開源的資料庫服務，提供了免費額度，而且功能非常強大：

- 提供 PostgreSQL 資料庫（功能強大的關係型資料庫）
- 內建使用者認證功能（註冊、登入、密碼重置等）
- 提供檔案儲存功能，可以存圖片、影片等
- 實時資料同步，資料變化時自動更新
- 友好的視覺化介面，不用寫 SQL 也能管理資料

![](https://pic.yupi.icu/1/image-20260109114906767.png)

而且 Supabase 的文件非常詳細，配合 AI 工具使用特別方便。你只需要告訴 AI：“用 Supabase 做一個使用者註冊功能”，AI 就能幫你寫好程式碼。

除了 Supabase，還有一些其他選擇：

- PlanetScale：MySQL 資料庫，有免費額度
- MongoDB Atlas：NoSQL 資料庫，有免費額度

如果你想進一步快速學習資料庫，可以看看 [魚皮的資料庫快速入門影片](https://www.bilibili.com/video/BV1iJSLBbEyD/)。



### 程式碼片段管理 - 程式碼小抄

在開發過程中，你可能會遇到一些好用的程式碼片段，想儲存下來以後用。或者你遇到 Bug 了，想把程式碼分享給別人幫你看看。這時候就需要程式碼片段管理工具了。

我強烈推薦自己團隊開發的 [程式碼小抄](https://codecopy.cn/)。這是一個簡單易用的程式碼分享工具，可以快速、跨裝置地自由分享程式碼。

![程式碼小抄](https://pic.yupi.icu/1/1705646241236-26786c47-1251-4891-85f3-e91ac9e4be94-20240125151504219-20240222165129145.png)

程式碼小抄的優勢：

- 介面很像程式設計師常用的編輯器，可以新增、刪除程式碼片段
- 支援多種分享範圍（公開、加密、僅個人可見）
- 支援多種分享方式（複製連結、QQ 分享、手機掃碼、微信小程式等）
- 還有程式碼庫功能，可以檢視並學習其他同學分享的優質程式碼
- 支援線上執行程式碼、AI 智慧程式碼分析和糾錯

無論是電腦或手機，都能獲得不錯的閱讀體驗。而且完全免費，不用擔心程式碼洩露。

**求求了！找別人改 Bug 時，不要再拍模糊不清的照片、或者直接在聊天裡發程式碼了**，用程式碼小抄分享，對方看起來會舒服很多。

做網站或應用時，經常需要一些圖示和圖片素材。下面是一些免費的資源網站：

免費圖片：

- [Pexels](https://www.pexels.com/)：免費圖片和影片素材

這些資源都可以免費使用，而且質量很高。配合 AI 工具使用，可以快速做出漂亮的網站。
