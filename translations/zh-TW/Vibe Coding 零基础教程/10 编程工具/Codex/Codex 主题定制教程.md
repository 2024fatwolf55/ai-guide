## Codex 定製主題實戰

我自己試著用 Codex + GPT 5.6 做了一套火影忍者宇智波佐助的主題，整個過程分享給大家。

![](https://pic.yupi.icu/1/1784207621768-328cf53a-9040-4aff-ab34-31345f1cbb5b-20260716221035511.png)

首先開啟 Codex，直接跟 AI 說：

```markdown
使用這個開源專案，幫我更換 Codex 的主題 https://github.com/Fei-Away/Codex-Dream-Skin
```

AI 會自動把倉庫克隆下來，檢查你的執行環境（Node.js 版本、系統平臺等），然後執行安裝指令碼。

![](https://pic.yupi.icu/1/1784207655690-1954481c-4005-4f35-b79d-54ef80ea605b.png)

安裝完成後，AI 會先幫你用專案自帶的預設主題跑一遍，確保環境沒問題。

然後你會看到 Codex 的介面已經發生了變化，說明換膚引擎生效了。

接下來，你可以直接讓 AI 幫你生成完全個性化的素材。

比如我跟 AI 說：

```markdown
幫我生成火影忍者宇智波佐助的背景圖，以及指令碼支援的一些額外的定製元素圖片，我要進行全方位的替換。
```

GPT 5.6 可以直接生圖（就是比較慢），它幫我生成了一套完整的佐助主題素材，包括佐助與須佐能乎的寬屏背景、宇智波透明紋章、側欄暗紋、千鳥雷電角飾，還有最重要的萬花筒寫輪眼。

![](https://pic.yupi.icu/1/1784207704853-20f3956a-9e10-49e7-b1d0-e5e1a3cac81a.png)

生成完畢後 AI 會自動把素材應用到 Codex 上。

不過由於主題可定製的元素太多了，第一遍生成的效果大機率有些地方看著不太舒服。

比如我這裡發現有些文字的配色在深色背景下不太好辨認，直接跟 AI 說哪裡不對就行：

```markdown
好像還有些文字顯示的配色是有問題的
```

![](https://pic.yupi.icu/1/1784207724134-00b62172-2e55-49f8-bc75-d27e46427461.png)

整個過程下來，從零到一套完整的自定義主題，操作上幾乎沒什麼門檻，就是跟 AI 對話而已。可惜有點慢，大部分時間是在等 AI 生圖和調色。



## 它是怎麼實現的？

可能有同學好奇，Codex 又沒有官方的主題介面，這個專案是怎麼做到換膚的？

其實原理並不複雜，Codex 桌面端本質上是一個 Electron 應用，介面是用 Web 技術渲染的。這個專案利用了 CDP（Chrome DevTools Protocol 瀏覽器除錯協議）在本機迴環地址 127.0.0.1 注入自定義的 CSS 和 JavaScript，相當於給 Codex 的介面疊了一層裝飾。

整個注入過程只走你自己電腦的本機地址，不涉及任何外部網路通訊，也不會修改 Codex 官方的 `.app` 安裝包和程式碼簽名，只是在介面層面加了一層視覺效果。想恢復的時候讓 AI 幫忙跑一下專案自帶的 Restore 指令碼就行，一條命令回到原樣，不影響後續正常更新。

![](https://pic.yupi.icu/1/01_Codex%E6%8D%A2%E8%82%A4%E5%8E%9F%E7%90%86%EF%BC%9AElectron%E5%BA%94%E7%94%A8%E9%80%9A%E8%BF%87CDP%E5%9C%A8%E6%9C%AC%E6%9C%BA%E6%B3%A8%E5%85%A5CSS_JS%E5%AE%9E%E7%8E%B0%E6%8D%A2%E8%82%A4_compressed_v1.png)
