# Cursor 保姆級教程：一篇搞定 AI 程式設計第一課

AI 程式設計工具的競爭已經進入了白熱化階段，國外有 Cursor、Claude Code、Codex 三巨頭，國內有位元組的 TRAE、阿里的 Qoder、騰訊的 CodeBuddy 三劍客。

其中，Cursor 算是我最早為之付費的產品了，雖然現在它因為價格等原因被人詬病，但仍然是非常能打的主流 AI 程式設計工具，而且更新嘎嘎快。

![](https://pic.yupi.icu/1/1_cursor.png)

我自己用 Cursor 做了不少專案，燒的錢也最多。這篇文章我會從安裝開始，帶你用 Cursor 從 0 做出一個完整的網站專案，完整走一遍 AI 程式設計的流程。看完之後，你就能用 Cursor 獨立完成各種 AI 程式設計任務了。

乾貨密集，建議先收藏，找個安靜的地方慢慢食用~



## 1、安裝和基礎準備

### 下載安裝

開啟 [Cursor 官網](https://cursor.com)，網站會自動識別你的作業系統，直接下載安裝包，一路點下一步就行了，跟裝微信一樣簡單。

![](https://pic.yupi.icu/1/image-20260604161516577.png)

安裝完成後開啟 Cursor，先註冊一個賬號。建議用 GitHub 賬號來註冊登入，因為後面做專案的時候會用到 GitHub 來管理程式碼和部署上線，提前關聯好會方便很多。

![](https://pic.yupi.icu/1/image-20260604161539548.png)



### 兩種介面

Cursor 提供了兩套操作介面。

一套叫 Agent Window，是不是有點眼熟？

跟你平時用的 AI 聊天工具長得差不多，左邊管理對話和專案，中間跟 AI 聊天，適合新手上手。

![](https://pic.yupi.icu/1/image-20260604161607946.png)

另一套叫 Editor Window，就是一個完整的程式碼編輯器介面，左邊看檔案、中間寫程式碼、右邊跟 AI 對話、底部開啟終端，適合管理複雜的程式碼專案。

![](https://pic.yupi.icu/1/image-20260604161653209.png)

兩種介面可以同時開啟、隨時切換。我建議新手先從 Agent Window 開始用，介面更簡潔，上手零門檻。等你對 Cursor 熟悉了，再切到 Editor Window。



### 免費版和付費版

Cursor 預設提供免費的 Hobby 套餐，可以體驗基本的 AI 對話功能，但模型能力和使用額度都有限制。

如果你要認真學 AI 程式設計，建議至少開通 Pro 套餐，每月 20 美元（約 150 元人民幣）。更高階的 Pro+ 和 Ultra 套餐主要是增加了用量額度，功能上跟 Pro 是一樣的，不夠用了再升級就行。

![](https://pic.yupi.icu/1/image-20260604161759761.png)



### 選擇 AI 模型

Cursor 的 Pro 使用者可以自由選擇 AI 模型。Cursor 支援 Claude、GPT、Gemini、Grok 等國外主流大模型，你可以在對話面板的模型選擇器裡一鍵切換，還能調節模型的推理等級。

![](https://pic.yupi.icu/1/image-20260604161830863.png)

不知道選什麼的話，直接用 Auto 模式就好，Cursor 會自動幫你選合適的模型，既省心又省錢。等你熟練了之後，可以根據任務複雜度手動切換，比如簡單任務用便宜快速的模型，複雜任務切到更強的模型。

![](https://pic.yupi.icu/1/image-20260604161906303.png)

好了，基礎準備搞定了，接下來正式體驗 Cursor 的 AI 能力。



## 2、認識 Cursor 的幾種能力

### Agent 模式初體驗

新開一個對話，預設就是 Agent 模式。這是 Cursor 最核心、最常用的模式，AI 可以自己分析需求、建立檔案、呼叫工具、寫程式碼、執行命令，一條龍完成任務。

先來個簡單的，讓 AI 幫你做一份 AI 程式設計熱點的網頁報告：

```plain
今天有哪些值得關注的 AI 程式設計熱點？
總結為一份 HTML 網頁報告
```

AI 會自動聯網搜尋最新資訊，然後幫你整理總結，生成一份 HTML 網頁檔案。

![](https://pic.yupi.icu/1/image-20260604161950784.png)

看看效果，只需要跟 AI 說一句話，天下熱點盡在你手~

![](https://pic.yupi.icu/1/image-20260604162054901.png)



### 其他互動方式

除了 Agent 模式，Cursor 還有幾種輕量的互動方式。

Ask 模式是純問答，執行速度快，但是不能修改檔案，適合你想了解某個知識點、或者讓 AI 解釋一段程式碼的時候用。

![](https://pic.yupi.icu/1/image-20260604162242454.png)

用編輯器模式寫程式碼的時候，AI 還會自動預測你下一步要寫什麼，按 Tab 就能接受建議，形成「Tab, Tab, Tab」的連續補全節奏。

![](https://pic.yupi.icu/1/image-20260604162414383.png)

選中一段程式碼按 `Cmd+K`（Mac）或 `Ctrl+K`（Windows），還能彈出一個小對話方塊，直接讓 AI 在當前位置修改程式碼，更輕量。

![](https://pic.yupi.icu/1/image-20260604162514930.png)

不過有了 Agent 模式之後，大多數情況你已經不需要自己動手寫程式碼了。Agent 模式才是 Cursor 真正的殺手鐧，接下來我們用它做一個完整的程式設計專案。



## 3、AI 程式設計實戰 - 網頁總結工具

### 搞清楚要做什麼

做專案的第一步始終是需求分析，先搞清楚你要做什麼。

這個工具的功能很簡單，就是使用者輸入一個網址，AI 自動提取網頁內容並生成摘要總結，幫你快速理解一篇文章的核心內容，省去逐字閱讀的時間。

像我平時要大量閱讀國外的技術部落格和新聞，有了這個工具就方便多了。



### Plan 模式 - 先想清楚再動手

建立一個空資料夾作為專案目錄，注意路徑最好是純英文的，中文路徑有時候會導致一些奇怪的相容問題。

然後在 Cursor 的 Editor Window 中開啟這個資料夾，在對話面板裡把模式切換到 Plan（按 `Shift+Tab` 可以快速切換模式）。

![](https://pic.yupi.icu/1/image-20260604162640727.png)

Plan 模式的好處是 AI 會先幫你想清楚怎麼做，生成一份實施計劃，確認沒問題後再動手寫程式碼。這樣可以避免 AI 一上來就亂寫一通。

我假設自己什麼技術都不懂，直接把需求丟給 AI：

```plain
幫我開發一個網頁總結工具，功能如下：

1. 使用者在頁面上輸入一個網址
2. 點選按鈕後，自動提取該網頁的內容
3. 然後用 AI 對內容進行總結概括，生成簡潔的摘要
4. 支援中英文網頁，結果都用中文展示
5. 介面要簡潔美觀，有載入動畫

請先幫我規劃一下整體的技術方案和實施步驟
```

AI 會分析需求，有任何不確定的地方會彈窗找你確認。然後輸出一份詳細的實施計劃，包括技術選型、檔案結構、任務列表。你不需要看懂計劃裡提到的每個技術名詞，大致掃一遍覺得合理就行。

![](https://pic.yupi.icu/1/image-20260604162743435.png)



### Agent 自主開發

確認計劃沒問題後，點選對話中的「Build」按鈕，AI 就開始按照計劃自主執行了。

它會自動建立專案檔案、編寫前端頁面、寫後端介面、配置 AI 模型呼叫。如果計劃中有多個可以同時進行的步驟，Cursor 還可能會啟動多個子 Agent 並行工作，加快速度。

![](https://pic.yupi.icu/1/image-20260604162815059.png)

幾分鐘後，AI 完成了開發，還會自動執行專案，並且在 Cursor 內建的瀏覽器面板中自動開啟網頁，你可以直接預覽效果，不用切到外部瀏覽器。

![](https://pic.yupi.icu/1/image-20260604162844304.png)



### 測試驗證

專案跑起來之後，AI 會告訴你需要準備什麼。由於我們的專案使用了 DeepSeek 大模型的 API 來做總結，需要先去 DeepSeek 開放平臺獲取一個 API Key，填到專案的環境變數檔案裡。

![](https://pic.yupi.icu/1/image-20260604162915371.png)

然後試試看效果。我輸入一篇文章的網址，點選總結按鈕，很快 AI 就給出了總結，還是很到位的。

![](https://pic.yupi.icu/1/image-20260604162946718.png)

但是我發現有些網站的內容無法正常提取和總結……

![](https://pic.yupi.icu/1/image-20260604163108311.png)

人工一個個測試太麻煩了，我們可以讓 AI 自己來測試和修復。

輸入 `@Browser` 使用 Cursor 內建的 Browser Use 瀏覽器操控功能，讓 AI 自主測試：

```plain
請你自主測試和修復 AI 提取和總結功能，確保相容大多數網站
比如當我輸入 https://ai.codefather.cn 時，報錯：未提取到足夠正文
```

![](https://pic.yupi.icu/1/image-20260604163149159.png)

AI 先分析了當前的程式碼，然後透過終端命令嘗試復現 Bug，修復了程式碼，還開了一個子 Agent 來開啟瀏覽器自動驗證。

![](https://pic.yupi.icu/1/image-20260604163216526.png)

修復完成後再試一次，這次就能夠正常總結了。

![](https://pic.yupi.icu/1/image-20260604163242010.png)

每次任務執行完成後，你可以檢視程式碼改動，按需保留或者撤銷部分修改，也可以直接點選 Keep 保留全部改動。建議每驗證完成一個功能就 Keep 一下。

![](https://pic.yupi.icu/1/image-20260604163307654.png)



### 迭代最佳化

AI 程式設計的核心思路就是「先完成再迭代」，第一版做出來之後，透過多輪對話不斷調整，直到滿意為止。

這個過程中，有幾個 Cursor 的核心技巧值得一提。



#### 用 @ 引用精準提供上下文

在對話方塊裡輸入 `@`，可以讓 AI 精準地參考你指定的內容。比如 `@檔名` 引用專案中的某個檔案，`@Docs` 引用已索引的官方文件，`@Terminals` 引用當前終端的報錯資訊。

![](https://pic.yupi.icu/1/image-20260604163359832.png)

比如你要用 Ant Design 元件庫來美化網站，可以用 `@Docs` 引入 Ant Design 的官方文件，AI 就能基於最新的文件來編寫程式碼，避免編造過時的寫法。

你也可以直接把檔案拖拽到對話方塊裡。比如我把自己的產品資訊文件拖進來，AI 在做底部版權推薦的時候就知道該展示什麼資訊了。

![](https://pic.yupi.icu/1/image-20260604163419853.png)

Cursor 還支援直接把圖片拖進對話方塊。比如你覺得蘋果官網的設計風格好看，截張圖粘進來讓 AI 參考著修改就行。

![](https://pic.yupi.icu/1/image-20260604163438613.png)

執行上述提示詞後，網站被最佳化成了下面這樣，還不錯吧~

![](https://pic.yupi.icu/1/image-20260604163550109.png)



#### Checkpoints 快照回滾

多輪修改的過程中，難免會遇到 AI 越改越亂、或者一個 Bug 始終解決不了的情況。

這時候用 Cursor 的快照回滾功能就好了。Agent 每次修改都會自動儲存一個快照，你只要把滑鼠懸停在對話記錄中之前某條訊息上，點選回滾圖示，就能一鍵恢復到那個時間點的程式碼狀態。

![](https://pic.yupi.icu/1/image-20260604163729304.png)

就像遊戲裡的存檔功能，搞砸了可以讀檔重來。



#### 檢視用量

做了這麼多操作，消耗了多少 AI 額度呢？

在對話方塊的右下角可以看到當前對話的上下文使用情況，包括消耗了多少 Token 和各部分佔比，一目瞭然。

![](https://pic.yupi.icu/1/image-20260604163751198.png)

你也可以開啟 [Cursor 後臺面板](https://cursor.com/dashboard) 檢視一段時間的消耗明細，建議給每月的按需用量加個上限，防止破產。

![](https://pic.yupi.icu/1/image-20260604163907596.png)

恭喜你，到這裡你已經用 AI 從 0 做出了一個完整的網頁應用！



## 4、讓 Cursor 更強 - 擴充套件能力

Cursor 本身已經很強了，但它還有一套擴充套件體系，可以讓 AI 連線外部工具、獲取最新資訊、遵守你的編碼規範。

![Cursor 外掛系統](https://pic.yupi.icu/1/image-20260604163937041.png)



### MCP - 讓 AI 連線外部世界

MCP 的全稱是 Model Context Protocol，聽起來很唬人，但你可以把它理解為 AI 的萬能插頭。原本 AI 只能根據訓練資料來回答問題、生成程式碼，但有了 MCP，它就能連線各種外部工具和資料來源，比如查天氣、運算元據庫、規劃出行路線。

![](https://pic.yupi.icu/1/mcp%E6%9E%B6%E6%9E%84%E5%9B%BE.png)

比如安裝高德地圖的 MCP，只需要去高德開放平臺申請一個 API Key，然後在 Cursor 設定裡配置一下就行：

```json
{
  "mcpServers": {
    "amap-maps": {
      "url": "https://mcp.amap.com/mcp?key=你的API_KEY"
    }
  }
}
```

![](https://pic.yupi.icu/1/image-20260604164139668.png)

配置完成後，能夠在 Cursor 設定面板中看到 MCP Server 提供的工具列表：

![](https://pic.yupi.icu/1/image-20260604164305442.png)

來試一試，直接跟 AI 說：用高德地圖幫我規劃一次週末上海兩日遊，查一下明天天氣，推薦適合的景點。

![](https://pic.yupi.icu/1/image-20260604164341317.png)

AI 就會自動呼叫高德地圖的各種工具，整合成一份完整的出遊方案。

![](https://pic.yupi.icu/1/image-20260604164403560.png)

像我現在分析自己的產品資料時，就用資料庫 MCP 讓 AI 直接連線資料庫查詢資料，省得自己寫 SQL 語句了。



### Skills - 給 AI 裝技能包

Skills 你可以理解為給 AI 提供的技能包，裝了某個技能後，AI 在遇到相關任務時就能自動按照這套方法來幹活，不用你每次都寫一大堆提示詞。而且技能是按需載入的，只有任務匹配時才會呼叫，不會浪費上下文空間。

![](https://pic.yupi.icu/1/04_Agent_Skills%E6%8A%80%E8%83%BD%E5%8C%85%E6%B8%90%E8%BF%9B%E5%BC%8F%E6%8A%AB%E9%9C%B2_original_v2%E5%A4%A7.jpeg)

比如 AI 程式設計時常用的幾個技能，用於聯網搜尋的 Firecrawl、用於獲取最新技術文件的 Context7、用於美化前端頁面的 UI UX Pro Max 等等。

安裝技能很簡單，以 Firecrawl 為例，直接到官網複製一行安裝命令，開啟終端執行，按照指引完成授權就好。

![](https://pic.yupi.icu/1/image-20260604164539466.png)

安裝完成後，在對話中輸入 `/firecrawl` 就能呼叫：

```plain
/firecrawl 魚皮的 AI 導航有哪些資源？
```

你會發現，Firecrawl 目前比 Cursor 內建的網頁搜尋工具效果更好、搜尋結果更全面。

![](https://pic.yupi.icu/1/image-20260604164606348.png)

你還可以用 Cursor 內建的 `/create-skill` 命令來建立自己的技能。比如你剛做完一個網頁總結工具，覺得這個流程以後還會重複用到，就可以讓 AI 把這次的工作流程封裝成技能，以後遇到類似任務就省事兒了。

![](https://pic.yupi.icu/1/image-20260604164634591.png)



### Rules - 約束 AI 的行為

用 Cursor 做專案的時候，你可能會發現 AI 生成的程式碼風格跟你的習慣不太一樣。比如你希望註釋用中文寫，但 AI 老是寫英文註釋。

最簡單的方式是在專案根目錄建立一個 `AGENTS.md` 檔案，用 Markdown 寫上你希望 AI 遵守的規則：

```markdown
## 編碼規範

- 所有程式碼註釋使用中文
- 使用 TypeScript 而非 JavaScript
- 變數命名使用駝峰式（camelCase）
```

儲存之後，AI 在當前專案中工作時就會自動遵循這些規則。

![](https://pic.yupi.icu/1/image-20260604164704104.png)

這個檔案不是 Cursor 獨有的，Claude Code、Codex 等主流 AI 程式設計工具都會讀取它，寫一份規則就能在多個工具間通用。

如果你需要更精細地控制規則在什麼時候生效，Cursor 還有一套專門的規則系統。

在設定面板的 Rules 配置中，可以建立針對特定檔案型別生效的規則，也可以讓 AI 智慧判斷是否需要某條規則。

![](https://pic.yupi.icu/1/image-20260604164827576.png)

不過對於剛入門的同學來說，用 `AGENTS.md` 就完全夠了。



## 5、進階功能速覽

到這裡你已經掌握了 Cursor 日常使用中最核心的功能。

此外，Cursor 還有不少進階能力，現在不需要深入學，知道有這些東西就行，做專案的時候遇到了再回來查。

1）Cloud Agent 雲端智慧體：前面我們用的 Agent 都是跑在自己電腦上的。

Cursor 還有一種 Cloud Agent，跑在雲端伺服器上，關掉電腦它也能繼續工作，適合大規模程式碼重構這種耗時任務。你甚至可以在手機上開啟網頁，隨時隨地讓 AI 幹活和檢視進度。

![](https://pic.yupi.icu/1/image-20260604165027452.png)

2）Automations 自動化：可以設定定時觸發或者事件觸發的自動化任務。比如讓 AI 每天早上 9 點自動整理專案進度並生成報告，或者當 GitHub 倉庫有人提交程式碼時自動做程式碼審查。

![](https://pic.yupi.icu/1/image-20260604165053532.png)
