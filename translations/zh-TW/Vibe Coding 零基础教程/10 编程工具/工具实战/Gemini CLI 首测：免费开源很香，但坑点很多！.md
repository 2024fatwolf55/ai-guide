# Gemini CLI：Google 的免費 AI 命令列工具實測

你好，我是魚皮。

Google 推出了一個很有意思的 AI 命令列工具 —— Gemini CLI，直接把 AI 塞進了終端裡。

![](https://pic.yupi.icu/1/1750927083919-e42152fe-9df9-4686-b813-388ae261b738.png)

根據 [官方介紹](https://github.com/google-gemini/gemini-cli)，這個工具能：

- 處理大型程式碼庫（高達 100 萬的 Token 上下文）
- 有多模態能力：能從 PDF 或草圖生成新應用
- 能自動化運維：幫你查詢程式碼合併請求、處理複雜的程式碼合併
- 整合了大量工具：支援連線 MCP 伺服器，支援影象、影片、音訊生成
- 還有內建搜尋等等

對標 Claude Code，現在還有免費使用額度、而且最好的是程式碼開源！

![](https://pic.yupi.icu/1/image-20260112165459541.png)

截止到 2026 年 1 月，Gemini CLI 已經有 **9 萬+ GitHub Stars**，火箭式漲星！

那這個工具到底怎麼樣呢？我來帶大家實際體驗一下，說說我自己真實的使用感受。

## 一、安裝和啟動

按照官方提供的文件，我們要先安裝 Node.js 執行環境，直接去 [官網](https://nodejs.org/) 安裝就好了，**注意版本要 >= 20**（2026 年最新要求）。

然後開啟終端，輸入一行命令全域性安裝工具：

```bash
npm install -g @google/gemini-cli
```

或者用 Homebrew 安裝（macOS/Linux）：

```bash
brew install gemini-cli
```

安裝完成後，輸入 `gemini` 命令，做一些基礎的設定：

![](https://pic.yupi.icu/1/1750927215041-aef86c7f-90b6-41e1-8509-cb53809372dd.png)

接下來是關鍵了，需要經過一波賬號驗證，個人使用者選第一項就好。

![](https://pic.yupi.icu/1/1750927255279-3b2d860a-c514-492a-8b27-a8abe27b4b31.png)

這裡大家可能會遇到 2 種驗證失敗的情況，第一種是網路原因（這個不好搞），第二種是說賬號型別不符合要求，如圖：

![](https://pic.yupi.icu/1/1750927301003-4937f694-3fc9-493f-8309-e169439f59fa.png)

對於第二種情況，解決方案很簡單。進入 [Google Cloud](https://console.cloud.google.com/) 控制檯，新建一個專案得到 `project_id`：

![](https://pic.yupi.icu/1/1750927486133-ecf76c02-ba82-4f85-adfe-4d168247bee6.png)

然後在終端輸入下列命令設定環境變數，重試就能登入進去了：

```bash
export GOOGLE_CLOUD_PROJECT=<你的 project_id>
```

登陸成功後，我們就可以開始使用了。

## 三、Gemini CLI 的優缺點

測試了 8 個維度後，我的感受是 **一言難盡**，可能是我對 Google 預期太高了吧。

### 優點

先說說優點。**終端操作本地檔案確實更方便**，而且它可以直接一行命令安裝，在已有的終端中使用，不用重新下載一個終端軟體，這點還是不錯的。

而且 Gemini CLI 最大的優勢是 **完全免費**（有免費額度），支援 Gemini 2.5 Pro 模型，100 萬 Token 上下文視窗，每天 1000 次請求。對於預算有限的開發者來說，這是個很好的選擇。

另外，Gemini CLI 是 **完全開源** 的（Apache 2.0 協議），支援 MCP 伺服器整合，可以擴充套件各種功能。

### 缺點

但是問題也很明顯。

首先是 **AI 智慧體的效果一般**，對自然語言理解能力不夠，會多幹、幹跑偏、幹錯。而且速度比較慢，簡單的問題也要等很久。

其次是 **互動體驗不夠好**。終端的互動體驗確實是不如網頁和客戶端的，很難看到思考過程，介面展示和互動效果也就那樣。檔案選擇器經常卡頓，選擇檔案很不方便。

還有就是 **使用門檻比較高**。非程式設計師使用它的門檻還是比較高的，需要熟悉終端操作。而且有些功能需要額外配置，比如 Google Cloud Project。

### 適合什麼人？

利用 AI 來生成一下終端命令我覺得很棒（比如 Warp AI），但如果你非要在這個框裡使用 AI 來生成內容，我覺得大可不必吧。

Gemini CLI 可能對擅長 Linux 伺服器操作的技術大佬還有點用，但是在公司伺服器上用這個還是要注意安全性。



## 寫在最後

看到這裡，相信你已經對 Gemini CLI 有了全面的瞭解。

我覺得 Gemini CLI 中規中矩吧，沒有到網上鋪天蓋地吹噓的那種程度。現階段這玩意更適合嚐鮮和學習，而不是作為日常提效工具來使用。

不過雖然現在體驗一般，考慮到 Google 的技術實力、還有開源免費的發展模式，我相信隨著版本迭代，這工具也會越來越好的。**而且對我們來說多一種工具的選擇，總不是壞事。**

如果你預算有限，又想嘗試命令列 AI 工具，Gemini CLI 是個不錯的選擇。但如果你追求最好的體驗，還是建議用 Claude Code。
