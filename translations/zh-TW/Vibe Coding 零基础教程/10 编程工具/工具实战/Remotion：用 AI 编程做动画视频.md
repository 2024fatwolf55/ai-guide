> 從安裝到出片，全程手把手



你好，我是程式設計師魚皮。

AI 程式設計能做的事情遠比你想象的多。除了做網站、做工具、做小程式，還能做動畫影片！

最近我發現一個很有意思的開源專案叫 [Remotion](https://github.com/remotion-dev/remotion)，能用寫程式碼的方式做影片動畫，在 GitHub 上星星很多。

![](https://pic.yupi.icu/1/image-20260216222601866.png)

你可能會問：用程式碼做影片？那不得累死？

用 AI 程式設計做動畫的原理其實很簡單：

- AI 寫程式碼

## 一、安裝 Remotion

首先，開啟終端，輸入一行命令快速安裝 Remotion：

```bash
npx create-video@latest
```

執行之後，它會問你幾個問題：

1. 選一個模板 > 我選了 Hello World
2. 專案名叫什麼 > 就叫 `myvideo`
3. 是否使用 TailwindCSS > 用唄
4. 是否新增 AI 智慧體技能 > 這個一定要加！

![](https://pic.yupi.icu/1/1770370961690-58c49ba5-aecf-4194-8f27-d2db91db6087.png)

新增了這個技能之後，你就可以透過 AI 對話的方式，讓 AI 幫你用這個庫做動畫了。

安裝技能的時候，它會問你裝到哪些智慧體裡、是當前專案安裝還是全域性安裝。我建議直接全域性安裝，省得以後每個專案都要重新裝一遍。

> 注意：你需要確保自己能訪問 GitHub，不然可能會報錯。

安裝完成後，進到專案目錄，安裝依賴並執行：

```bash
npm install
npm run dev
```

![](https://pic.yupi.icu/1/1770372083166-73703f97-3ef2-4980-922d-0b3a0116245d.png)

開啟瀏覽器，你會看到一個 **Web 端的影片剪輯工具**：

![](https://pic.yupi.icu/1/1770372166367-c5facfbf-1829-4b03-8dde-5e86ed1064f2.png)

看看這介面，不知道的還以為是客戶端軟體呢！

頁面左側展示了不同的影片片段，每個片段其實都是透過程式碼渲染出來的。你刪掉一段程式碼，對應的影片就沒了：

![](https://pic.yupi.icu/1/1770372458099-64e9f878-ebf6-42b9-9c78-bde4e5fd40e2.png)

在程式碼編輯器中按 Ctrl+Z 撤回，影片又出來了。是不是挺神奇的？

![](https://pic.yupi.icu/1/1770372446540-126bd94f-f484-4631-8813-086a27c05b50.png)

## 三、用素材最佳化影片

由於動畫是 AI 做的，它可能比我更清楚需要哪些素材、以及放到哪些位置，所以我讓 AI 來引導我完善素材。

傳送提示詞：

```
現在的動畫有點生硬，缺少真實的圖片、背景音樂和音訊，請你引導我應該怎麼完善這些內容，我是傻子
```

AI 就會開始透過互動提問的方式來引導我，一步步告訴我該做什麼。

![](https://pic.yupi.icu/1/1770374563833-99fb5a74-a01e-4b03-a40e-6c524cf79f05.png)

## 四、最佳化思路

目前動畫影片存在 2 個比較嚴重的問題，我說一下自己的最佳化思路。

**問題 1、素材不夠真實**

如果完全讓 AI 用程式碼繪製素材（SVG、Emoji 之類的），出來的東西比較抽象。所以建議自己多補充一些真實的圖片素材，效果會好很多。

**問題 2、聲音和畫面歌詞對不上**

可以先讓 AI 生成歌詞以及對應的時間線，然後把這個時間線同時交給 AI 做動畫影片和 AI 生成音訊。這樣兩邊都是按照同一個時間線來編排的，畫面和聲音就能對上了。



## 寫在最後

用 AI 程式設計的方式來做影片，在畫面真實感和流暢度上肯定沒法跟 Seedance、Sora、可靈這些影片生成模型比較。但它有自己的優勢，比如完全可控、可編輯、可復現，而且不需要消耗 GPU 算力和昂貴的影片 API 費用，純靠程式碼渲染就行。只要你描述到位、再人工多補充一些素材，做出來的效果其實也能滿足很多場景。

我覺得這個工具比較適合做下面幾類影片：

- 動畫演示影片：比如講解一個知識點，讓 AI 幫你變成動畫
- 快閃文字類影片：歌詞快閃、文字動效這類
- 抽象整活影片：雞你太美這種梗影片
- 知識科普動畫：雖然看起來生硬，但能幫別人快速理解知識
