## 主流 AI 程式設計工具

#### Cursor

開局先來個王炸，Cursor 是目前全球最火的 AI 程式設計工具，沒有之一。背後的公司估值已經接近 500 億美元，堪稱 AI 程式設計賽道的超級獨角獸。

我是 Cursor 的重度使用者，不止一個 Ultra 賬號，每月消耗上萬元，現在 80% 的專案程式碼、以及日常的工作流都用它來實現。

說下我看重 Cursor 的原因，首先 Agent 模式又快又穩，Claude、GPT、Gemini 各種主流模型都能一鍵切換，想用哪個用哪個，而且能夠支援 100M 上下文。

其次開發體驗很好，外掛管理、MCP 配置、模型設定這些都有視覺化介面，可以隨時檢視 Agent 執行狀態和終端資訊。

AI 程式設計能力加上視覺化的開發體驗，綜合來看在同類工具裡 **基本沒有對手**。

![](https://pic.yupi.icu/1/1_cursor.png)

而且 Cursor 的更新迭代非常頻繁，到現在已經有 Cloud Agents 雲端並行、Browser Use 瀏覽器自動化測試、Design Mode 直接在介面上選中元素讓 AI 改程式碼、內建 AI 生圖等等能力了。還提供了命令列版本和網頁版，手機上開啟網頁就能隨時隨地操作 Agent 幹活。

不過跟大多數國外 AI 程式設計工具一樣，國內使用有一定的網路門檻。免費版只能使用 Auto 模式提供的免費額度，即使自己配置了國內模型也不能用。

此外，Cursor 是基於 VS Code 開源版本實現的，但介面整體不如原生 VS Code 精緻，Markdown 的閱讀體驗能最佳化下就更好了。

看一下價格，真心不便宜啊！Ultra 一個月 200 刀，賬單燒的嘎嘎猛，這可能也是很多人棄用 Cursor 的原因。

| 套餐 | 價格 |
|:-----|:-----|
| Free | 免費（有限 Agent 和補全額度） |
| Pro | $20/月 |
| Pro+ | $60/月 |
| Ultra | $200/月 |
| Teams | $40/使用者/月 |

還有朋友詬病 Cursor 是覺得它們沒有強大的自研模型，覺得未來可能會因為模型被卡脖子，拼不過 Claude Code 和 Codex。

不管怎麼說，這個工具確實徹底改變了我的工作方式，而且幾乎沒有解決不了的問題。如果有，那就是 Tokens 沒燒夠。



#### GitHub Copilot

接下來是曾經的王者 GitHub Copilot。

Copilot 的產品形態非常豐富，有 VS Code 外掛、GitHub 網頁版、還有命令列終端，覆蓋面是所有工具裡最廣的。畢竟是微軟官方出品，和 VS Code 的整合是真的好，介面優雅、互動體驗我覺得是所有工具裡最舒服的。MCP 和 Skills 等外掛擴充套件也可以視覺化管理，能力也很齊全。

![](https://pic.yupi.icu/1/2_copilot.png)

我還帶大家用 GitHub Copilot 網頁版搭建過一個能自主開發、上線、修 Bug 的智慧體。

![](https://pic.yupi.icu/1/1774937381654-bde29eb7-3d0f-4869-a065-f7ddb09950dd-20260514180312605.png)

曾經 Copilot 的價效比巨高，每月 10 刀就能用上 Opus 模型，還有 30 天免費試用，那會兒真的是王者。但現在官方扛不住成本了，好日子到頭了，使用門檻變高了不少。6 月 1 號開始還要切換到按 Token 計費的模式，上下文也有 20 萬的限制。

跟其他國外工具一樣，國內使用也有一定的網路門檻。

| 套餐 | 價格 |
|:-----|:-----|
| Free | 免費（50 次 Agent + 2000 次補全/月） |
| Pro | $10/月 |
| Pro+ | $39/月 |
| Business | $19/使用者/月 |

免費版的額度對於輕度使用來說還算夠用，Pro 版 $10/月也不貴。但要注意 6 月起計費模式要變了。



#### Codex

OpenAI 的 Codex 最近更新速度嘎嘎快，奧特曼說它正在經歷 ChatGPT 時刻。

Codex 的介面主打一個簡潔，第一眼看上去甚至不像 AI 程式設計工具，更像個 AI 聊天助手。但實際上功能很全面，MCP 擴充套件、Skills 技能包、外掛市場、自動化、Git 整合、Browser Use、Computer Use 這些工程能力基本都具備了。最近甚至還搞了個 AI 桌面寵物加情緒價值。。。

![](https://pic.yupi.icu/1/3_codex.png)

Codex 也獨創了一些 AI 程式設計玩法，比如推出了 `/goal` 命令，可以設定一個持久目標讓 AI 自主工作數小時，不需要人工干預。

不過 Codex 目前 **預設** 只能使用 GPT 系列模型（可以用 CC Switch 等工具快速修改），程式設計能力上 GPT-5.5 整體還是不錯的，基本能一把梭搞定全棧專案，但前端表現中規中矩，整體不如 Claude Opus 和使用了 Claude 模型的 Cursor。而且對我來說目前 GPT-5.5 的 20 多萬的輸入上下文真心不夠用，這是致命傷！

Codex 的易用性也差一些，比如配置 MCP 服務要手寫資訊，不像 Copilot 可以一鍵安裝，檢視程式碼的體驗也不如基於 VS Code 生態的 Cursor 方便。

跟其他國外工具一樣，國內使用需要網路工具，也需要 ChatGPT 訂閱。

| 套餐     | 價格          |
| :------- | :------------ |
| Plus     | $20/月        |
| Pro      | $200/月       |
| Business | 按 Token 計費 |

我自己是 Plus 會員，做一個全棧專案大概用掉 5 小時額度的一半，1 周差不多能做 10 個完整小專案。

等什麼時候能讓使用者輕鬆自由切換模型了、上下文達到 100 萬了、或者最佳化一下讀寫程式碼的體驗，Codex 還有很大的提升空間。

再次強調，我並沒有說 Codex 不好，大家不要激動。我寫過多篇 Codex 實戰教程，所有的理由也都列舉出來了，我只是希望他能做的更好。



#### Windsurf

我對 Windsurf 最深的印象是，之前經歷了 OpenAI、Google 的收購風波。

巨頭能看上，說明產品本身有東西。

Windsurf 核心的 Agent 叫 Cascade，能跨多個檔案自主規劃和執行多步編輯。被收購之後還整合了 Devin，可以一鍵把複雜任務委派給雲端執行，本地和雲端雙路協作。它還有個 Memories 功能，Agent 會逐漸學習你的程式碼庫架構和編碼風格，用得越久建議越精準。

![](https://pic.yupi.icu/1/4_windsurf.png)

Windsurf 的價格跟 Cursor 基本持平。不過跟 Cursor 比起來，模型靈活度和社群生態還是有差距的，國內同樣有網路門檻。

| 套餐 | 價格 |
|:-----|:-----|
| Free | 免費 |
| Pro | $20/月 |
| Max | $200/月 |
| Teams | $40/使用者/月 |



#### Trae 國際版

Trae 是位元組跳動的 AI IDE，分為國內版和國際版，二者在模型、定價、多模態能力等地方的差異都很大，所以我把它們分開講。

國際版預設整合了 GPT、Gemini、DeepSeek 等多家主流模型，支援用自己的 API Key 使用 Claude。功能上主打的是 SOLO 模式，具備長期記憶，能全自動開發、測試、除錯和部署專案。而且新上線了移動端 App，手機上也能操作。

![](https://pic.yupi.icu/1/5_trae.png)

不過國際版和其他國外工具一樣有網路門檻。

看看它的定價，Pro 版只要 $10/月，差不多是 Cursor 的一半價格，價效比不錯。

| 套餐 | 價格 |
|:-----|:-----|
| Free | 免費（基礎額度） |
| Lite | $3/月 |
| Pro | $10/月 |
| Pro+ | $30/月 |
| Ultra | $100/月 |



#### Kiro

Kiro 是 AWS 推出的 AI IDE，跟其他工具最大的不同是它主打「規格驅動開發」。

簡單說就是你不能一上來就讓 AI 寫程式碼。Kiro 會要求你先用自然語言描述需求，然後它自動生成需求文件、設計文件和任務清單這 3 份檔案，你審批透過之後它才會開始寫程式碼。

有點像計劃模式，但是比計劃模式更嚴謹。所有設計意圖都版本控制在倉庫裡，還有 Agent Hooks 功能，比如檔案儲存的時候能自動觸發測試和文件更新。

![](https://pic.yupi.icu/1/6_kiro.png)

但對於絕大多數剛上手 AI 程式設計的同學來說，改個小功能還得先走一遍規格審批，把簡單的事搞麻煩了。

價格方面跟 Cursor 相當，Kiro 的預設模型在國內是可以直接使用的，有一定的免費額度。

| 套餐 | 價格 |
|:-----|:-----|
| Free | 免費（50 Credits） |
| Pro | $20/月 |
| Pro+ | $40/月 |
| Power | $200/月 |



#### Zed

Zed 是輕量級的 AI 編輯器，剛釋出 1.0 正式版。

它主打的就是極致效能，根據官方資料，冷啟動只要 180 毫秒，記憶體佔用才 100 多 MB。

它還內建了 120fps 的實時多人協同編輯，不需要裝任何外掛就能多人同時寫程式碼，AI 功能方面也有 Agent 面板和並行多 Agent。

![](https://pic.yupi.icu/1/7_zed.png)

不過整體成熟度跟 Cursor 還是有差距的，擴充套件生態也比較小。說實話，現在用 AI 程式設計，大部分時間都在等 AI 思考和輸出，編輯器本身快一點兒的優勢感知不太明顯。

Zed 的 Pro 版定價 $10/月，差不多是 Cursor 的一半價格，學生還可以免費用一年，價效比還行。

| 套餐 | 價格 |
|:-----|:-----|
| Personal | 免費 |
| Pro | $10/月 |
| Business | $30/seat/月 |



#### Antigravity

Antigravity 是 Google 推出的 Agent-first IDE，它整合了編輯器、終端和內建瀏覽器三個工作面，Agent 可以橫跨這三個面自主執行任務，最多支援 5 個 Agent 並行。你只需要審批結果就行，Agent 還會生成截圖、錄屏、程式碼 diff 這些可驗證的交付物，方便你確認質量。模型方面不僅支援 Google 自家的 Gemini，Claude Opus 也能用。

![](https://pic.yupi.icu/1/8_antigravity.png)

不過由於是 Google 的產品，國內使用嘛，你懂的。。

看一下價格，Pro 版跟 Cursor 差不多，Ultra 版 $250/月 比 Cursor 的 Ultra 還貴一些。

| 套餐 | 價格 |
|:-----|:-----|
| Free | 免費預覽 |
| AI Pro | $19.99/月 |
| AI Ultra | $250/月 |

Antigravity 自從釋出之後，更新節奏不如 Cursor 和 Codex 那麼頻繁，最近存在感有點低了。



#### Trae 國內版 / Qoder / 騰訊 CodeBuddy

位元組的 Trae 國內版、阿里的 Qoder、騰訊的 CodeBuddy，是國內 AI 程式設計 IDE 的御三家。功能比較接近，最大的共同優勢就是 **國內直連無障礙，不需要任何網路工具**。

**Trae 國內版** 跟國際版有些差距，模型換成了豆包 Seed Code、DeepSeek、Kimi 等國產模型，但核心 AI 程式設計功能完全免費無限制（就是得排隊）。

![](https://pic.yupi.icu/1/9_trae_cn.png)

**Qoder** 底層用的自研 Qwen-Coder 模型，國內版也支援接入第三方模型。它有個 Repo Wiki 功能，可以自動生成專案知識圖譜，適合理解大型程式碼庫。

![](https://pic.yupi.icu/1/9_qoder.png)

**騰訊 CodeBuddy** 在產品形態上比較全面，有獨立 IDE、VS Code/JetBrains 外掛、還有命令列版本。CodeBuddy 最大的亮點是跟微信生態的深度整合，支援微信小程式開發和企業微信 Bot 整合，搞微信相關開發用它比較合適。

![](https://pic.yupi.icu/1/9_codebuddy.png)

三個工具的價格：

| 工具 | 免費版 | 付費版 |
|:-----|:-------|:-------|
| Trae 國內版 | 核心功能免費無限制 | 企業版 69 元/人/月起 |
| Qoder | Community 免費 | Pro $20/月起，Teams 中國區 300 元/席位/月 |
| CodeBuddy | 個人免費（限時） | 企業旗艦 198 元/人/月 |

這三家都還在快速迭代的階段，功能上跟 Cursor 這種國際頂流比還有差距，但好在國內直連、免費、中文體驗好，對於初學者和預算有限的同學來說是非常好的入門選擇。

我真心希望國內的 AI 程式設計工具能越做越好，儘早追上國際一線水平。



#### OpenCode

OpenCode 是開源的終端 AI 程式設計工具，GitHub 上有十幾萬 Star！

OpenCode 的優勢在於完全免費開源，支援非常多的模型提供商，提供了 Scout Agent 程式碼庫研究功能，對程式碼庫的理解和導航比較方便。而且還出了桌面應用和 VS Code 擴充套件。

![](https://pic.yupi.icu/1/10_opencode.png)

我在它剛火的時候就試過了，當時印象最深的是前端介面做的非常漂亮，使用者體驗上碾壓 Claude Code。但後端工程能力跟 Claude Code 還是有差距的。

那問題來了，如果只是追求前端使用方便，我為啥不直接用 Cursor 呢？如果追求極致的程式設計能力，Claude Code 又更強。

不過 OpenCode 提供了一些免費模型，能夠幫小白練手。



#### Warp

Warp 是定位比較特殊的 AI 終端工具，最近剛剛開源了。

它跟 Claude Code、OpenCode 這類終端 AI 程式設計工具有個本質區別，其他工具是你在終端裡執行一個 AI 程式，而 Warp 本身就是一個終端軟體，給整個終端增加了智慧化，像是終端和桌面端的混合體。

![](https://pic.yupi.icu/1/11_warp.png)

不過實際體驗下來，我覺得有點兒不上不下。既然要用 AI 程式設計，我不如直接去用 Cursor 這種有完整介面的工具，效率更高。而且 Warp 缺少新使用者的引導，小白上手會有點兒懵。

看一下價格，也不便宜。

| 套餐 | 價格 |
|:-----|:-----|
| Free | 免費（前 2 月 150 Credits，之後 60 Credits/月） |
| Build | $18/月起 |
| Max | $180/月起 |
| Business | $45/使用者/月 |

最氣人的是，我還沒用幾次就給我封號了？還是說想讓我付費？簡直莫名其妙。



#### Goose

Goose 是一個開源 AI Agent，目前已經捐給了 Linux 基金會。

它有個 Recipes 功能，可以把擴充套件、提示詞和設定打包成可複用的工作流模板分享出去，MCP 擴充套件生態也很豐富，但沒什麼其他的亮點了。

![](https://pic.yupi.icu/1/12_goose.png)

不過 Goose 的知名度太低了，整體生態過於小眾。



#### Aider

Aider 是開源的終端 AI 程式設計工具，GitHub 上有好幾萬 Star。

它的特點是跟 Git 深度繫結，改完程式碼自動 commit 還順帶寫好描述。還有個 Architect 模式，可以用強模型規劃任務、便宜模型來寫程式碼，節省 API 費用。

但是我試了一下，使用體驗一言難盡，連呼叫工具都能失敗，給我一種 23 年 AI 剛出時的感覺，怪不得生態那麼小眾。。

![](https://pic.yupi.icu/1/13_aider.png)



#### Claude Code

如果說 Cursor 是視覺化 AI 程式設計的王者，那 Claude Code 就是命令列 AI 程式設計的絕對霸主！

Claude Code 是 Anthropic 推出的終端程式設計 Agent，處理複雜任務的能力沒得說，妥妥的 Number 1。在 SWE-bench 基準測試中拿下了 80.8% 的行業最高分。

它還是很多 AI 程式設計新能力和規範的引領者。比如 CLAUDE.md 持久記憶檔案，最早就是在 Claude Code 中推出的，後來被行業標準化為 AGENTS.md，其他工具紛紛跟進。還有 Hooks 事件驅動系統、Subagents 子智慧體架構、Agent Teams 多 Agent 協作這些機制，也都是透過 Claude Code 率先落地的。

![](https://pic.yupi.icu/1/14_claudecode.png)

對了，前段時間 Claude Code 不是還把原始碼送給大家學習了？這是推動整個行業進步啊！

不過它的使用是有一定門檻的。一方面需要有命令列基礎，對於大多數只會視覺化操作的同學來說不太友好。隨便舉個例子，Claude Code 怎麼檢視終端任務的進行狀態？你讓小白摸索試試？

另一方面，Claude Code 預設使用自家的 Claude 模型，國內不能直接使用。不過現在可以用 CC Switch 之類的工具切換到國內模型來解決。

雖然互動體驗上不如 Copilot、Cursor、Codex 這些視覺化工具直觀，但命令列有自己的優勢，靈活方便、在任何終端環境裡都能用。

如果你想追求最強的 AI 程式設計能力，還是建議學習一下命令列操作。我寫過很多篇 Claude Code 的實戰教程，大家都能跟著學。

再看一下價格。每月 20 刀的 Pro 計劃主要提供 Sonnet 模型，想在 Claude Code 中用最強的 Opus 模型得開每月 100 刀的 Max 套餐，還是挺貴的。

| 套餐 | 價格 |
|:-----|:-----|
| Pro | $20/月（Sonnet 4.6） |
| Max 5x | $100/月（Opus 4.6） |
| Max 20x | $200/月 |
| API | 按量計費 |

Claude Code 作為命令列 AI 程式設計的絕對標杆，AI 程式設計能力最強、新正規化的引領者，非常值得關注和學習。

主流的 AI 程式設計工具就介紹完了。除了這些之外，還有幾類產品也能拿來做 AI 程式設計，雖然定位不完全一樣，但各有各的用處。



## AI 程式設計外掛

不知道你們現在還用不用「AI 程式設計外掛」？就是安裝在 IDE 裡，可以用來程式碼補全什麼的。

我是幾乎不用了。。。

這些外掛非常多，而且功能高度重疊，所以我講的時候會偷個懶兒，合併一下同類項。



#### 通義靈碼 / 百度 Comate / CodeGeeX

先說國內 AI 程式設計外掛的早期三幻神，阿里的通義靈碼、百度的 Comate 和智譜的 CodeGeeX。

這三家的核心能力都差不多，程式碼補全、程式碼解釋、單元測試生成、多語言支援這些。國內可以直連使用，中文體驗很好。

![](https://pic.yupi.icu/1/%E9%80%9A%E4%B9%89%E7%81%B5%E7%A0%81.png)

不過 25 年之後，這幾個產品就沒有太大的風浪了，在 Cursor、Claude Code 這些工具面前存在感越來越弱。



#### Cline

Cline 是開源 AI Agent 外掛裡的標杆，GitHub 上有 6 萬多 Star。

相比前面那三家國產外掛，Cline 最大的優勢在於 Agent 能力更強，支援 Plan & Act 雙模式和 Checkpoints 回滾機制，改壞了可以一鍵回到之前的狀態。

![](https://pic.yupi.icu/1/cline.png)

Cline 在 VS Code 外掛市場的安裝量有幾百萬，在全球開發者中口碑不錯，社群活躍度也一直線上。



#### Kilo Code / JetBrains Junie / Continue / Augment Code

然後是一些整體存在感不算高的 AI 程式設計外掛，我估計很多同學都沒聽說過，我放在一起講。

**JetBrains Junie** 是 JetBrains 自家的 AI Agent，它可以完全委派任務自主執行，利用 IDE 的語法樹做編譯器級別的糾錯。但是隻支援 JetBrains 系 IDE，不支援 VS Code，而且需要改賬號地區才能用。

![](https://pic.yupi.icu/1/junie.png)

**Kilo Code** 本質上是 Cline 的一個 fork 分支，走了商業化路線。支援的模型和平臺很多，覆蓋 VS Code、JetBrains、CLI、移動端等，還有 Memory Bank 持久化專案上下文的功能。

**Continue** 模型自由度很高，不過配置確實比較複雜，上手門檻偏高。

**Augment Code** 號稱大型程式碼庫的專家，Context Engine 可以索引大量檔案。但已經開始封區了，國內註冊困難，價格也不便宜。

這些外掛雖然各有特色，但在當前 AI 程式設計外掛賽道里整體存在感偏弱，功能上也很難跟主流 AI IDE 競爭。



#### Tabnine

我記得 Tabnine 應該是我上大學那會兒很火的程式碼補全外掛，但現在已經全面轉向企業市場了。免費版停了，個人付費版也在下架，目前只剩企業套餐，普通開發者基本用不了。

![](https://pic.yupi.icu/1/tabnine.png)



## AI 低程式碼平臺

接下來是 AI 低程式碼平臺，這些平臺基本都長一個樣兒。簡單來說就是你輸入一句提示詞，然後它幫你生成完整的應用，還能自動部署上線。

這類平臺最重要的就是用起來方便，前端要美、後端要穩，生成速度要快。

為了公平對比，我全部使用免費版賬號，用同一個提示詞測試了所有平臺：幫我完全仿照魚皮 AI 導航網站，開發一個美食導航網站。

這個任務需要聯網搜尋我的網站，既考察 Agent 能力，又考察前端還原能力。

下面我們依次看看各個 AI 低程式碼平臺的表現。



#### Manus

Manus 耗時最長，花了 15 分鐘左右，但 **還原度是最高的**，把我網站的風格抓得很準。

![](https://pic.yupi.icu/1/manus.png)

我之前對 Manus 的印象其實是不好的，因為有一次我做影片給大家演示 Manus 結果被罵的很慘。。。

大家都覺得 Manus 的故事比它的產品還精彩，爆火、融資、裁員、跑路新加坡、被 Meta 20 多億收購、被國家發改委叫停，堪稱一部大型連續劇，AI 都不敢這麼演。

不過沒想到，我這次測試下來 Manus 表現竟然是最好的。Manus 主要擅長的是前端生成和自動部署，後端能力相對有限，更適合做展示型應用和 MVP 原型。

產品價格 $20/月起步。



#### v0.dev / Lovable / Replit Agent

**v0.dev** 是 Vercel 出品的，就是做知名前端框架 Next.js 的那家公司。用時 3 分 57 秒完成，**也還原了我網站的樣式**，效果非常好。

它最擅長的還是前端 UI 生成，雖然官方已經支援透過 Next.js Server Actions 和 API Routes 做一些後端邏輯了，但實際生成的後端程式碼質量還不太行，適合做原型不適合直接上生產。

![](https://pic.yupi.icu/1/v0dev.png)

**Lovable** 生成速度最快，3 分 08 秒就搞定了，但 **沒有還原我網站的樣式**。它更擅長從零開始生成 MVP，深度捆綁了 Supabase 做認證和資料庫，還有 Stripe 支付腳手架，對非技術背景的同學比較友好。

![](https://pic.yupi.icu/1/lovable.png)

**Replit Agent** 花了 6 分鐘，**也沒有還原我網站的樣式**。相比其他兩個產品，也沒有什麼獨特的功能。

![](https://pic.yupi.icu/1/replit.png)

價格上幾個平臺都差不多：

| 平臺 | 免費版 | 付費版 |
|:-----|:-------|:-------|
| v0.dev | Free（$5 月度積分） | Premium $20/月 |
| Lovable | Free（30 積分/月） | Pro $25/月 |
| Replit Agent | Free 可用 | Core $20/月，Pro $100/月 |



#### Bolt.new

我自己免費的 AI 程式設計教程中，使用 Bolt.new 作為小白開發 AI 應用的入門 Demo 製作工具。

結果這次實測下來，翻車了。。。它把需求想複雜了，直接進入了 Plan 模式，結果把我免費賬號的 Tokens 都燒完了，卻一行程式碼都沒寫出來。

![](https://pic.yupi.icu/1/boltnew.png)

贛！你讓新手怎麼用啊？

整體來說，這類 AI 低程式碼平臺更適合零基礎的新手快速入門，如果你追求更靈活強大的 AI 程式設計能力，還是用最開始提到的主流 AI 程式設計工具吧。



## AI Agent

最後說一下 AI Agent 類的產品。

AI Agent 是一種能自主完成複雜任務的智慧助手，你給它一個目標，它自己拆解任務、呼叫工具、一步步執行。

雖然下面這些並不是專業的 AI 程式設計工具，但它們也能拿來做 AI 程式設計，所以放到這裡給大家漲漲姿勢。

#### OpenClaw / Hermes Agent

OpenClaw 是一個開源的全能 AI 助手，它最大的優勢是可以接入微信、釘釘、飛書等各種平臺，隨時隨地給 AI 派活，做個 Demo 確實很方便。

![](https://pic.yupi.icu/1/openclaw.png)

我在它爆火的時候給大家出過很多篇教程，從保姆級安裝、到高階玩法、再到專案實戰全都有。

![](https://pic.yupi.icu/1/OpenClaw%E6%95%99%E7%A8%8B%E6%BC%94%E7%A4%BA-%E6%8A%80%E8%83%BD%E7%B3%BB%E7%BB%9F.png)

Hermes Agent 也是現在最流行的 Agent 產品之一，跟 OpenClaw 屬於同一類產品。但是它跟 OpenClaw 最大的區別在於它有「自進化能力」，每次解決問題後會自動生成可複用的技能，越用越聰明。

![](https://pic.yupi.icu/1/hermes.jpg)

我自己拿它們做過一些 Demo，只能說「能用」，但真要做正兒八經的專案，穩定性遠不如專業 AI 程式設計工具。要做完整專案的話，大機率還是得用 Cursor 或者 Claude Code 來接管。而且 tokens 燒麻了！普通人要麼不會玩，要麼玩不起。



## 寫在最後

總結一下。如果你剛入門 AI 程式設計，我推薦 **Trae 國內版** 零成本練手，進階的話用 **Cursor** 做實戰開發，想更深入就學習 **Claude Code** 的命令列操作。此外，Codex 也非常值得關注，等它能自由切換模型了，說不定會超越 Claude Code 呢？

整體來看，AI 程式設計能力 = 模型 + 工程。國產工具在工程層面的差距正在快速縮小，國外工具新出什麼能力，國內很快就能跟上。但在底層模型的推理能力上還有差距，很期待國產 AI 能把價格打下來，讓更多人用得起。

學會了這些內容，你就能根據自己的需求和預算，選擇最適合自己的 AI 程式設計工具。

如果你想繼續學習更多 AI 程式設計工具和實戰技巧，可以閱讀本教程程式設計工具板塊的其他文章。
