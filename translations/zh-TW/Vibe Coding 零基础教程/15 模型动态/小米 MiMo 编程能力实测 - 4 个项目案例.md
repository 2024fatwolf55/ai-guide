## 環境準備

### 安裝 Claude Code

先簡單介紹一下 Claude Code。它是 Anthropic 推出的 AI 程式設計工具，直接在終端裡執行，你跟它聊天描述需求，它就能自主分析專案、寫程式碼、跑命令、修 Bug，全程自主執行。

除了基礎的程式碼生成，還能使用工具和 Skills 技能包、連線 MCP 外部服務、用 Plugins 外掛擴充套件能力，甚至搞多智慧體協作，擴充套件性很強。目前最新的 v2.1 版本還加入了 Skills 熱過載、會話分叉、自定義主題等功能，更新嘎嘎猛。

![](https://pic.yupi.icu/1/1777516701789-b0eb659f-6674-46a4-bdc0-b2d50eda4503.png)

安裝 Claude Code 很簡單。

首先確保你的電腦有 Node.js 環境和 npm 軟體依賴安裝工具，沒有的話，直接到 [Node 官網](https://nodejs.org/en/download) 下載傻瓜式安裝包就好：

![](https://pic.yupi.icu/1/1777516701942-41e28c9d-4c6c-420f-b34a-3a771d840517.png)

無論使用什麼作業系統，都可以透過 npm，一行命令來安裝 Claude Code：

```bash
npm install -g @anthropic-ai/claude-code
```

![](https://pic.yupi.icu/1/1777516701568-eb7eda2d-4b39-4eb6-ac05-98c7316f0fd8.png)

安裝完成後，輸入 `claude` 命令進入對話介面，首次需要登入才能正常使用：

![](https://pic.yupi.icu/1/1777516701608-fc857d89-e5d0-4ce0-8aa6-ff3e3be676fe.png)

但估計很多同學沒有 Anthropic 的國外訂閱賬號，所以我們要切換為國產模型。



### 切換模型

Claude Code 本身是支援切換模型的，你可以透過「修改環境變數」或「編輯配置檔案」來對接其他大模型的 API。

一般你使用哪家的大模型 API，直接看對應的官方文件，就能找到接入方法。

比如 [小米開放平臺的 API 文件](https://platform.xiaomimimo.com/docs/zh-CN/integration/claudecode) 裡就有現成的接入方法，包括建立配置檔案和填寫環境變數：

![](https://pic.yupi.icu/1/1777516802254-f5e31401-fd22-4ade-9d79-9300e2aa23be.png)

不過我更推薦用一個開源工具 **CC Switch**，能夠視覺化地管理 Claude Code、Codex、Gemini CLI 等 AI 程式設計工具的配置，一鍵切換不同的模型供應商。內建了 50 多個供應商預設，不用自己手動改配置檔案。

> 開源指路：https://github.com/farion1231/cc-switch

按照官方中文文件，根據作業系統選擇對應的安裝方式：

![](https://pic.yupi.icu/1/1777516702429-c35e4af9-a053-4b50-a4eb-732ee54ba83a.png)

Mac 使用者可以透過命令列安裝：

```bash
brew tap farion1231/ccswitch
brew install --cask cc-switch
```

![](https://pic.yupi.icu/1/1777516702626-80669bdd-f79a-4eb7-8b50-c2761abd2e4f.png)

安裝完成後，執行軟體進入主介面，新增模型供應商：

![](https://pic.yupi.icu/1/1777516702459-9ec60a6b-3c67-4be6-ac68-05929b4c7e16.png)

可以看到 CC Switch 內建了海量的供應商預設，選擇 Xiaomi MiMo：

![](https://pic.yupi.icu/1/1777516868333-8935ba98-5740-4390-a91c-43726514d90c.png)

然後準備填寫模型配置資訊，需要先從 [小米開放平臺](https://platform.xiaomimimo.com/console/api-keys) 獲取 API Key。

**注意，如果你免費領取或者開通了小米模型的套餐，必須要使用專屬 API Key 和專屬 Base URL**，否則要麼訪問不了模型，要麼消耗的還是你的賬戶餘額。

專屬 Base URL 在套餐頁面可以看到，相容 OpenAI 和 Anthropic 兩種協議：

![](https://pic.yupi.icu/1/1777520404516-69102816-7223-47d6-9718-5c01695170e0.png)

在 CC Switch 中填寫好 API Key 和套餐專屬的請求地址：

![](https://pic.yupi.icu/1/1777519071552-5154a636-5ca3-4bec-8611-779d5d44577c.png)

然後設定使用的模型，我這裡把主模型設定為 MiMo-V2.5-Pro，它是小米的旗艦 Agent 模型，專為長難程式設計任務最佳化，token 效率更高。

點右下角儲存：

![](https://pic.yupi.icu/1/1777519244637-dee5554b-4a59-4d26-bdab-f1a9061b6ce2.png)

可以在上圖中看到 Claude Code 的 JSON 配置檔案，其實 CC Switch 就是幫你視覺化地修改各 AI 工具的配置檔案，省去手動編輯 JSON 的麻煩。

最後，啟用 Xiaomi MiMo 模型：

![](https://pic.yupi.icu/1/1777517330499-3376bc13-1ddc-4f91-a383-e7289ee94613.png)

然後重新進入 Claude Code，在左上角能看到切換後的模型名稱。隨便輸入一句話，AI 能給出回覆，說明切換模型成功：

![](https://pic.yupi.icu/1/1777517445474-f87c4e7b-f5fe-40c4-9d94-bf03881537a4.png)



### 安裝擴充套件

Claude Code 預設就有讀寫檔案、跑終端命令、搜尋程式碼這些基礎能力，但要做好一個完整專案，光靠這些還不夠。

我們需要下面 3 個擴充套件：

1. Frontend Design：前端美化技能，讓生成的頁面更有設計感
2. Firecrawl：聯網搜尋和網頁抓取，讓 AI 能獲取最新的技術資訊
3. Context7：查詢最新的技術文件和 API 用法，減少 AI 瞎編的情況

下面來依次安裝。



#### 1、安裝 Frontend Design

Frontend Design 是 Anthropic 官方的前端美化技能，可以讓 AI 生成的頁面更有設計感。

在 Claude Code 中，先透過 `/plugin` 命令新增官方技能市場，相當於裝了個技能商店：

```bash
/plugin marketplace add anthropics/skills
```

![](https://pic.yupi.icu/1/1777516703443-717324a1-5864-447b-a731-9e4a519b7c40.png)

輸入 `/plugins`，在 Discover 選單欄中，選中 `example-skills` 並按回車，安裝官方的示例技能合集：

![](https://pic.yupi.icu/1/1777516703538-4a99f67b-f288-4b8d-825e-0a2d6322a9f4.png)

輸入 `/reload-plugins` 過載一下外掛：

![](https://pic.yupi.icu/1/1777516703624-e34d36ab-a5e2-4487-9cf7-e7748a056b1a.png)

輸入 `/skills` 檢視已安裝的技能，可以看到 `frontend-design` 已經就位了：

![](https://pic.yupi.icu/1/1777516703673-3a14f336-7d1f-4796-8502-b74c61f47e16.png)

之後在對話方塊中輸入 `/frontend-design` 就能主動觸發這個技能，讓 AI 美化前端頁面。同時還自動裝上了 `webapp-testing` 自動化測試技能，後面也用得上。



#### 2、安裝 Firecrawl

Firecrawl 是聯網搜尋和網頁抓取工具，讓 AI 開發前先搜尋最新技術資訊。

安裝方式很簡單，開啟終端，輸入一行命令：

```bash
npx -y firecrawl-cli@latest init --all --browser
```

![](https://pic.yupi.icu/1/1777516703895-7e336a35-0dc6-4fae-8859-3f8c68f7bf5b.png)

執行後，會自動開啟瀏覽器，要在彈出的頁面中點選授權：

![](https://pic.yupi.icu/1/1777516704155-c203bf1d-0b6a-4c5d-b5c7-82649ef398ed.png)

安裝完成後，會自動註冊 12 個 Firecrawl 相關技能：

![](https://pic.yupi.icu/1/1777516704255-d77f6dd4-4366-4e4c-8d47-15c800539cab.png)

在 Claude Code 的技能管理中，就能看到新新增的 Firecrawl 相關技能了：

![](https://pic.yupi.icu/1/1777516704270-209e0bea-bc02-436f-80b0-9ccf7f19f48b.png)



#### 3、安裝 Context7

Context7 是一個技術文件查詢工具，讓 AI 能獲取到各種框架和庫的最新官方文件，避免用過時的 API 寫程式碼。

先在終端輸入一行命令來安裝：

```bash
npx ctx7@latest setup
```

它會問是安裝 MCP 服務還是 CLI + Skills，這裡我選擇 CLI + Skills。你會發現，現在越來越多工具已經從 MCP 轉向 CLI + Skills 的方式了：

![](https://pic.yupi.icu/1/1777516704783-e365125c-516f-4dab-b23a-491825737e13.png)

同樣在彈出的網頁中授權，不用自己獲取和輸入 API Key，太方便了！

![](https://pic.yupi.icu/1/1777516704558-12e8c7bf-608f-4cd6-88e8-d4201888ba27.png)

然後選擇要給哪個 AI 程式設計工具安裝，我選擇為 Claude Code 安裝：

![](https://pic.yupi.icu/1/1777516704721-42a91222-a15f-4213-b9b6-99a108c3d72b.png)

安裝成功後，可以在技能管理中看到 `find-docs` 技能：

![](https://pic.yupi.icu/1/1777516704847-83d065f0-1366-411f-819f-28601f74aae8.png)

當然，你也可以選擇安裝 MCP Server 的方式：

![](https://pic.yupi.icu/1/1777516704900-044ae1bc-6565-41b4-9bb0-7c71a8925e8b.png)

安裝後，在 Claude Code 中輸入 `/mcp` 命令，就能看到安裝好的 MCP 了，比自己手動配置方便太多了！

![](https://pic.yupi.icu/1/1777516705093-194d4d76-6279-4562-9030-6d111e9735c3.png)

至此，環境準備完成！下次開發專案時，就不用再重複準備了~



## 專案實戰測評

環境配好了，接下來就是重頭戲了。

我準備了 4 個不同型別的專案來測試小米 MiMo-V2.5-Pro 的實際程式設計能力，覆蓋不同維度：

1. 程式設計師魚皮的個人網站，測試前端設計和 UI 審美
2. 網站解讀器，測試全棧工程能力和 AI 整合
3. QQ 堂小遊戲，測試複雜互動邏輯和遊戲程式設計
4. Claude Code 原始碼分析網站，測試資訊架構和資料視覺化

為了節省時間和公平比較，每個專案我都用相同的提示詞結構，提前準備好技術方案直接給 AI。

實際 AI 程式設計時，如果你是零基礎的同學，完全可以讓 AI 幫你思考方案。

但這裡我想測的是模型的 **程式碼生成能力**，而不是方案設計能力，所以直接把方案餵給它，減少變數。

下面逐個來看。



### 程式設計師魚皮的個人網站

第一個專案，做一個程式設計師的個人主頁。

需求很簡單，就是展示個人資訊、技術棧、專案作品、文章動態這些內容。但要用 Aceternity UI 這個動畫元件庫，看看 AI 能不能做出有科技感的頁面。主要測試模型的 **前端設計能力和 UI 審美**。

每個 Case 都要單獨新建一個專案資料夾，在 Claude Code 中開啟：

![](https://pic.yupi.icu/1/1777517798429-58a4ae87-6db3-4941-adea-cddee5f05dd8.png)

輸入提示詞：

```markdown
## 角色

你是一個前端全棧工程師，擅長 Next.js + TypeScript 開發。

## 任務

開發「程式設計師魚皮」的個人網站，一個程式設計師 / 自媒體創作者的個人主頁。

包含以下模組：Hero 區（頭像、一句話介紹、社交連結按鈕）、關於我、技術棧展示、專案作品集（卡片式，支援分類篩選）、文章/影片動態（模擬資料）、聯絡方式 / Footer。

## 技術棧

- 框架：Next.js + TypeScript
- UI 元件：Aceternity UI（從官網複製元件程式碼整合，如 Hero Highlight、Bento Grid、Card Hover Effect、Floating Navbar 等）
- 動畫：Framer Motion（Aceternity UI 內建依賴）

## 要求

1. 頁面設計要現代、有科技感，深色主題為主，充分利用 Aceternity UI 的動畫元件（如背景光效、卡片懸浮、文字漸顯等）
2. 響應式適配手機和桌面端
3. 純靜態頁面，資料用 JSON 檔案或常量模擬
4. 開發前，先聯網搜尋 Aceternity UI 官網檢視可用元件列表和用法
5. 必須生成完整可執行的程式碼，完成後自主驗證
```

我這裡按 Shift + Tab 進入了自動接受編輯模式，透過自動批准檔案更改來消除每次操作都需要手動確認的提示，不用每次都找我確認。但是具有一定風險，大家按需使用。

再按一次 Shift + Tab 還可以進入 Plan Mode 計劃模式，但這裡我已經給出了方案，就不用計劃了，加速加速 gogogo！

開發過程中可能需要你確認是否要執行工具呼叫、執行 Skill 等資訊，可以選擇不用再次詢問。

等了近 10 分鐘，AI 完成了任務。

### 網站解讀器

第二個專案，來個全棧的。

使用者輸入一個網址，系統自動抓取網站內容，呼叫 DeepSeek V4 大模型進行全面分析，輸出功能定位、目標使用者、技術棧推測、SEO 評估等報告。

主要測試模型的 **全棧工程能力和 AI 整合能力**，看它能不能把前端、後端、爬蟲、大模型呼叫這條鏈路串起來。

輸入提示詞：

```markdown
## 角色

你是一個全棧工程師，擅長 React 前端 + Python 後端開發。

## 任務

開發一個「網站解讀器」Web 應用。使用者輸入一個網站 URL，系統自動抓取該網站內容，呼叫 AI 大模型進行全面分析，輸出：功能定位、目標使用者、技術棧推測、內容結構、SEO 評估、優缺點總結。

## 技術棧

- 前端：React + TypeScript (Vite 構建)
- UI 元件：Ant Design（antd）
- 後端：Python FastAPI
- 網頁抓取：後端使用 httpx + BeautifulSoup 抓取頁面內容
- AI 分析：後端呼叫 DeepSeek 模型（相容 OpenAI SDK），使用 SSE 流式返回結果
- 前後端通訊：前端透過 fetch 消費 SSE 流

## 要求

1. 前端介面使用 Ant Design 元件（Input、Card、Spin、Steps 等），佈局清晰專業
2. 支援流式輸出，分析過程實時逐字顯示
3. 後端做好錯誤處理（URL 無效、抓取超時、AI 呼叫失敗等），前端友好展示錯誤資訊
4. 前後端分離，分別提供啟動命令
5. 必須生成完整可執行的程式碼，完成後自主驗證
```

### QQ 堂小遊戲

這個專案主要測試模型的 **複雜互動邏輯和遊戲程式設計能力**，碰撞檢測、狀態機、AI 尋路這些，都是難啃的硬骨頭。

### Claude Code 原始碼分析

最後一個專案，做一個展示 Claude Code 架構設計和實現原理的網站，包含專案概覽、架構圖、核心模組詳解、流程圖、原始碼目錄結構這些模組，資訊量很大。

這個專案主要測試模型的 **資訊架構能力和資料視覺化能力**，看它能不能理解複雜系統並清晰地展示出來。

輸入提示詞，同時把 Claude Code 原始碼包的路徑提供給 AI：

```markdown
## 角色

你是一個全棧工程師，擅長 React 前端 + Python 後端開發，同時精通程式碼架構分析和資料視覺化。

## 任務

開發一個「Claude Code 原始碼分析」網站，系統性地展示 Claude Code（Anthropic 的命令列 AI 程式設計工具）的架構設計和實現原理。

包含以下模組：專案概覽（一句話定位 + 關鍵指標）、架構總覽圖（互動式模組關係圖，可點選展開詳情）、核心模組詳解（Agent 迴圈、Tool 系統、Context 管理、許可權控制等，每個模組一個詳情頁）、關鍵流程圖（使用者輸入→思考→工具呼叫→輸出的完整鏈路）、原始碼目錄結構（可展開的樹形瀏覽 + 搜尋過濾）。

## 技術棧

- 前端：React + TypeScript (Vite 構建)
- UI 元件：Mantine（使用其 AppShell、NavLink、Tabs、Accordion、Paper 等元件）
- 視覺化：React Flow 繪製架構圖和流程圖
- 後端：Python Flask，提供分析資料的 API（架構資訊、模組資料以 JSON 格式儲存）
- 前後端通訊：REST API

## 要求

1. 使用 Mantine 的 AppShell 做整體佈局（側邊導航 + 主內容區），支援亮/暗色模式切換
2. 架構圖使用 React Flow，支援節點點選展開詳情、縮放拖拽
3. 後端用 Flask 提供靜態 JSON 資料的 API，資料內容基於 Claude Code 的公開資訊整理
4. 支援全站搜尋，快速定位模組和關鍵概念
5. 前後端分離，分別提供啟動命令
6. 必須生成完整可執行的程式碼，完成後自主驗證
```

## 總結

最後簡單聊聊這次測試下來，我對小米 MiMo-V2.5-Pro 的真實感受。

先說能力。它是有能力完成全棧專案的，4 個任務都成功跑起來了。

但是質量嘛，一言難盡。

感覺它是個不太上進的 AI，只用最簡單的方式完成了我的任務，主打一個「能跑就行」，多做一點功能都不帶的。

怪不得官方宣傳 token 效率高呢，省 token 的方式就是少幹活？

從實際效果來看，整體程式設計能力不如 DeepSeek V4，跟 Claude Opus 就更沒法比了。

我測了 4 個任務，執行過程中竟然 **都沒有使用過我安裝的技能**（Firecrawl、Context7、Frontend Design），而是用了 Claude Code 內建的搜尋和抓取工具。這說明 MiMo-V2.5-Pro 在工具呼叫的決策上還不夠聰明，更好的工具就在手邊，它愣是沒用。

我覺得目前它比較適合開發一些工具類的小專案、或者解決一些日常程式設計小問題。如果想做複雜專案，還是要花心思編寫提示詞的，比如明確引導它使用技能、給出更詳細的方案設計，再加上人工幫忙把控。

說白了，模型不夠強的時候，提示詞和 Harness 工程就要做得更好。
