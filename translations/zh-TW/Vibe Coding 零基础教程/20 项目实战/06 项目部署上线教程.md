# 專案部署上線教程


你好，我是程式設計師魚皮。

在前面的文章中，我們學習瞭如何開發各種專案。但是如果專案只能在本地執行，那就太可惜了。這篇文章，我會教你如何把專案部署到網際網路上，讓全世界的人都能訪問。

需要先說明的是，如果你用的是 Bolt.new、Lovable、美團 NoCode、百度秒噠等 AI 零程式碼平臺，它們一般自帶了部署功能，點選發布按鈕就能上線，非常方便。但是如果你想更靈活地部署，比如使用自己的域名、選擇不同的伺服器、或者部署更復雜的全棧專案，那就需要學習更多的部署方式。

下面我會介紹多種部署方式，從最新的 AI 自動部署、到最流行的 Vercel 一鍵部署、再到專業的伺服器部署。你可以根據自己的專案型別和需求，選擇合適的部署方式。



## 一、部署方式概覽

在開始之前，先了解一下有哪些部署方式。

對於前端專案（靜態網頁、單頁應用等），最簡單的方式是使用託管平臺，比如 Vercel、GitHub Pages、EdgeOne Pages 等。這些平臺提供免費的託管服務，只需要上傳程式碼，就能自動部署並生成訪問連結。

對於全棧專案（包含前端和後端），可以選擇容器化部署（Docker）、雲伺服器部署（阿里雲、騰訊雲等）、或者 Serverless 部署。這些方式相對複雜一些，但功能更強大。

下面我會詳細介紹每種部署方式。



## 二、讓 AI 自動部署（最新最酷）

### 方式一、EdgeOne Pages MCP 自動部署

#### 準備工具

我們需要用到的工具包括：

- Cursor：AI 程式設計工具，負責呼叫 AI 生成程式碼
- EdgeOne Pages MCP：能夠將網站快速部署到 CDN 並生成公開訪問連結的服務

什麼是 EdgeOne Pages MCP 呢？拆解一下這幾個單詞。

EdgeOne 是騰訊雲提供的 CDN 加速服務，可以把使用者的網站資源快取到離使用者最近的邊緣節點，提升網站效能。

![](https://pic.yupi.icu/1/1752216739540-3dbb9132-3ae0-4a5d-9949-2a4299663c39.png)

EdgeOne Pages 是基於這個 CDN 的網站部署服務，可以讓你輕鬆地將網站部署到 CDN 上，並且得到公開訪問地址，完全不需要自己搭建伺服器。

![](https://pic.yupi.icu/1/1752216784265-0a71fe3a-7944-40b2-b5ce-87215df060fe.png)

MCP 則是目前很火的模型上下文協議，讓 AI 模型能夠輕鬆地使用各種工具來增強能力，完成更復雜的任務。

![](https://pic.yupi.icu/1/1752216828838-510154d5-6a89-4089-84b9-fadeccb9d724.png)

EdgeOne Pages MCP 的作用就顯而易見了 —— 給 AI 提供網站部署工具，這也是一個比較熱門的 MCP。

![](https://pic.yupi.icu/1/1752217054075-0f149a76-9e42-482e-ae26-e23762c7ad1e.png)



#### 快速實戰

1）開通 Pages 服務

首先到 [EdgeOne 控制檯](https://console.cloud.tencent.com/edgeone/pages) 開通 Pages 服務：

![](https://pic.yupi.icu/1/1752209404627-3a3193d9-4c94-4f80-ad02-435ff22f16ed.png)

開通服務後，預設進入了專案管理頁面，我們先不急著建立專案：

![](https://pic.yupi.icu/1/1752209421726-11d8eff7-7bdd-4a85-accf-c70f74ead15a.png)

由於等下要透過 MCP 完成網站部署，所以要先獲取 API Token，作為呼叫服務的憑證：

![](https://pic.yupi.icu/1/1752209504079-6741bbd0-438e-48a4-86be-6eddfc3efa83.png)



2）配置 MCP

新建一個專案資料夾 `yupi-blog`，在 Cursor 中開啟，然後進入設定，新增 MCP 服務：

![](https://pic.yupi.icu/1/1752209949437-369134bc-303b-46fc-bca1-e1a57a335f82.png)

將這段配置複製貼上到 MCP 配置檔案中：

```json
{
  "mcpServers": {
    "edgeone-pages-mcp-server": {
      "command": "npx",
      "args": ["edgeone-pages-mcp"],
      "env": {
        "EDGEONE_PAGES_API_TOKEN": "你的API Token",
        "EDGEONE_PAGES_PROJECT_NAME": ""
      }
    }
  }
}
```

注意要把 API Token 改成你自己的，並且把註釋刪除掉，否則會報錯：

![](https://pic.yupi.icu/1/1752210048110-15bf78cc-da14-4f7f-b9d5-3ec510332bf7.png)

正常情況下，你會看到 MCP 服務成功載入，綠了綠了！

![](https://pic.yupi.icu/1/1752211512400-a59c2010-8701-4b75-80d9-014ad03e8b4a.png)

這個服務提供了 2 個工具：

- deploy_html：部署 HTML 內容到 EdgeOne Pages，返回公開訪問 URL
- deploy_folder_or_zip：部署資料夾或 ZIP 檔案到 EdgeOne Pages，返回公開訪問 URL

注意，這個 MCP 服務需要 NPX 工具才能在本地成功啟動。NPX 可以直接執行 NPM 包中的命令而無需全域性安裝，常用於執行腳手架工具和一次性命令。

如果你沒有 NPX 命令、或者 Node.js 版本過低（最好不要低於 20），都會導致工具無法載入。

![](https://pic.yupi.icu/1/1752211437222-1400be90-e460-4948-b7f3-45a6a78ffe7d.png)

這時，你只需要到 [官網安裝 Node.js](https://nodejs.org/zh-cn)，會自動幫你安裝 NPM 和 NPX 工具：

![](https://pic.yupi.icu/1/1752209643527-73a7c2cc-046c-4faa-8531-2a22da95d4bd.png)

如果沒有自動安裝 NPX 工具，那就用 NPM 包管理工具安裝 NPX：

```bash
npm i -g npx
```

很快網站就生成並部署完成，可以看到 AI 呼叫了 MCP 部署 HTML 的工具，得到了訪問地址：

![](https://pic.yupi.icu/1/1752212029384-16cfba8f-babb-49c0-9d41-3b76ee78eecf.png)

直接開啟網址就看到效果了，不要太方便！

![](https://pic.yupi.icu/1/1752212096367-0a0fac32-118e-485a-9277-8dd507ff66d3.png)

不過目前生成的網站比較簡單，就一個 HTML 頁面，甚至沒有在本地建立程式碼檔案。

### 方式二、Vercel CLI + Skills 自動部署

除了 EdgeOne Pages，Vercel 也是非常主流的部署平臺，同樣支援 AI 自動部署。

國外主流的免費部署平臺還有：

1）Netlify 是一個老牌的前端託管平臺，內建了表單處理、身份驗證等開箱即用的功能，免費額度也挺大方。

![](https://pic.yupi.icu/1/1779164654949-9ccf2948-71b2-4e64-8e80-69304b3b5684.png)

2）Cloudflare Pages 背靠全球最大的 CDN 廠商 Cloudflare，全球訪問速度快，而且免費額度夯爆了，每天 10 萬次請求都不收費！

![](https://pic.yupi.icu/1/1763643429297-d14df879-2841-47ee-92f7-448dbcbebbc1.png)

這些平臺都支援從 GitHub 倉庫匯入專案並一鍵部署，也都提供了 Skills 或 MCP 來讓 AI 程式設計工具自動完成部署操作。而且不只能部署純靜態頁面，Next.js、Nuxt、Astro 這些全棧框架的網站也能直接丟上去，支援 SSR 服務端渲染。

下面以 Vercel 為例，帶大家完整走一遍 AI 自動部署的流程。

假設已經用 AI 開發好了一個「程式設計寶典」文件網站，基於 VuePress 構建，程式碼也推到了 GitHub 上開源。這是一個精簡版的模板專案，大家可以直接 fork 拿來練手。

> 開源指路：[https://github.com/liyupi/codefather](https://github.com/liyupi/codefather) （template 分支）

![](https://pic.yupi.icu/1/image-20260526190336965.png)



#### 什麼是 Vercel？

先簡單介紹一下 Vercel。它是目前海外最主流的網站部署平臺，你把程式碼丟給它，它能幫你構建、託管、CDN 加速，還自動配好 HTTPS，完全不需要自己搭建伺服器。而且跟 GitHub 深度整合，之後每次推送程式碼都會自動重新部署，非常省心。

![](https://pic.yupi.icu/1/image-20260526190516543.png)

為了讓 AI 程式設計工具能幫我們操作 Vercel，Vercel 官方提供了 3 樣東西：

1）Vercel CLI 命令列工具：在終端裡執行 `vercel` 命令就能完成部署，可以讓 AI 幫你呼叫。

![](https://pic.yupi.icu/1/01_CLI_%E5%91%BD%E4%BB%A4%E8%A1%8C%E5%B7%A5%E5%85%B7%E6%A6%82%E5%BF%B5%E5%9B%BE_-_%E7%BB%88%E7%AB%AF%E6%89%A7%E8%A1%8C%E9%83%A8%E7%BD%B2%E5%91%BD%E4%BB%A4_compressed_v3.png)

2）Skills 技能包：Skill 是一種標準化的指令檔案，相當於給 AI 看了一遍 Vercel 的部署教程。裝了之後 AI 就知道完整的操作流程和最佳實踐，遇到問題也知道怎麼處理。

![](https://pic.yupi.icu/1/02_Skills_%E6%8A%80%E8%83%BD%E5%8C%85%E6%A6%82%E5%BF%B5%E5%9B%BE_-_AI_%E5%AD%A6%E4%B9%A0%E9%83%A8%E7%BD%B2%E6%95%99%E7%A8%8B_compressed_v1.png)

3）MCP 模型上下文協議：讓 AI 直接呼叫 Vercel 的 API 來管理專案，比如建立部署、配置環境變數等。

![](https://pic.yupi.icu/1/03_MCP_%E6%A8%A1%E5%9E%8B%E4%B8%8A%E4%B8%8B%E6%96%87%E5%8D%8F%E8%AE%AE%E6%A6%82%E5%BF%B5%E5%9B%BE_-_AI_%E7%9B%B4%E6%8E%A5%E8%B0%83%E7%94%A8API_compressed_v3.png)

我們這裡主要用 **CLI + Skills** 的組合來演示。相比 MCP，Skills 不需要額外配置服務端，而且一次安裝後，各種 AI 程式設計工具都能直接用。



#### 快速實戰

**1、註冊 Vercel 賬號**

首先到 [Vercel 官網](https://vercel.com) 註冊賬號，建議直接用 GitHub 賬號登入，這樣後面匯入專案會很方便：

![](https://pic.yupi.icu/1/image-20260526181239984.png)



**2、安裝 Vercel CLI**

Vercel 提供了命令列工具，可以讓我們透過終端完成部署。

先開啟終端，用 npm 全域性安裝：

```bash
npm i -g vercel@latest
```

![](https://pic.yupi.icu/1/image-20260526181611414.png)

安裝完之後，在終端執行 `vercel login`，並且在彈出的網頁中完成登入認證：

![](https://pic.yupi.icu/1/image-20260526181842915.png)



**3、安裝 Vercel Skills**

接下來給 AI 程式設計工具裝上 Vercel 的部署技能 `deploy-to-vercel`。裝了之後，AI 在幫你部署的時候就能自動檢測專案狀態、選擇最佳的部署方式、生成預覽連結。

![](https://pic.yupi.icu/1/image-20260526182147054.png)

開啟終端，輸入下列命令，可以安裝 Vercel 團隊提供的多個技能：

```bash
npx skills add vercel-labs/agent-skills
```

你可以自己選擇要安裝哪些技能，這裡我就單選一個部署技能：

![](https://pic.yupi.icu/1/image-20260526183143004.png)

技能預設會被安裝到大多數 AI 程式設計工具都支援的 `.agents/skills` 目錄下，你也可以安裝在特定 AI 程式設計工具的技能目錄下，比如安裝到 Claude Code 支援的 `.claude/skills` 目錄：

![](https://pic.yupi.icu/1/image-20260526183209335.png)

最後，選擇「全域性安裝」還是「當前專案下安裝」，我一般選擇全域性，省的每個專案都要單獨裝一遍。

![](https://pic.yupi.icu/1/image-20260526183233033.png)

安裝成功後，你的 AI 程式設計工具（Cursor、Claude Code、Codex 等）就會自動載入這些技能，在 AI 需要的時候幫你用上。

![](https://pic.yupi.icu/1/image-20260526185018067.png)

除了技能之外，你也可以配置 Vercel 的 MCP 服務，二選一就好。

直接進入 [Vercel MCP 的官方文件](https://vercel.com/docs/agent-resources/vercel-mcp#cursor)，點選「Add to Cursor」按鈕：

![](https://pic.yupi.icu/1/image-20260526183455202.png)

會自動跳轉到 Cursor 的設定頁面，點選 Install 就能完成安裝了，然後完成授權即可，非常傻瓜式：

![](https://pic.yupi.icu/1/image-20260526183551677.png)



**4、讓 AI 幫你部署**

準備工作搞定，下面在 AI 程式設計工具中開啟你的專案目錄，就可以開始部署了。

這裡選擇使用 Claude Code 來演示，但 Cursor、Codex 等其他 AI 程式設計工具的用法都是一樣的。

安裝 Skills 之後，會多出一個 `/deploy-to-vercel` 斜槓命令。直接在跟 AI 對話時輸入這個命令，就能觸發部署流程，比手打提示詞更方便、成功率也更高。

```
/deploy-to-vercel 幫我把當前專案部署到 Vercel
```

![](https://pic.yupi.icu/1/image-20260526190722865.png)

AI 會自動幫你完成以下操作：

1. 檢測當前專案型別（比如識別出這是一個 VuePress 專案）

## 三、Vercel 一鍵部署（推薦）

[Vercel](https://vercel.com) 是目前最流行的前端部署平臺，特別適合 React、Next.js、Vue、靜態網站等前端專案。

Vercel 的優點是個人專案完全免費，部署速度極快（一般 1 ~ 2 分鐘），自動配置 HTTPS 和 CDN 加速；還和 GitHub 深度整合，能夠在你推送程式碼到 GitHub 倉庫後自動部署。



### 使用步驟

1）首先訪問 [Vercel 官網](https://vercel.com) 註冊賬號，建議使用 GitHub 賬號註冊登入。

2）建立專案，可以直接繫結 GitHub 並選擇已經託管的專案，點選 "Deploy" 部署按鈕：

![](https://pic.yupi.icu/1/image-20260109111323983.png)

3）等待 1 ~ 2 分鐘，專案就上線了！

部署成功後 Vercel 會自動給你一個域名，比如 `your-project.vercel.app`，你也可以繫結自己的域名。而且每次你往 GitHub 推送程式碼，Vercel 都會自動重新部署，完全不用手動操作。



### 命令列部署

除了網頁操作，Vercel 還提供了命令列工具，可以讓我們透過一行命令把自己的專案部署到平臺。先用 NPM 安裝 Vercel CLI 工具：

```bash
npm i -g vercel@latest
```

然後，直接在想部署的專案資料夾下輸入 `vercel` 命令，就能部署當前專案了：

![](https://pic.yupi.icu/1/1752218682107-8c8457e4-3fbe-40d8-afb8-f6cb0691beee.png)

讓 AI 完成自動部署的方法也很簡單，你只需要在提示詞中告訴 AI “你可以使用 vercel 命令列工具完成網站部署”，聰明如它，一定能幫你完成任務。

💡 具體過程可以看魚皮的影片教程：https://www.bilibili.com/video/BV1TV4y1j76t

除了 Vercel，還有 [Netlify](https://www.netlify.com/) 這個類似的平臺。Netlify 和 Vercel 功能差不多，但功能更全面一些，支援更多的框架和靜態站點生成器，有表單處理、無伺服器函式等功能，免費額度更大、還支援 A/B 測試和分析。使用方式和 Vercel 類似：註冊賬號 => 連線 GitHub => 選擇專案 => 點選部署。如果你的專案不是 Next.js（Next.js 用 Vercel 最好），可以考慮用 Netlify。



## 四、GitHub Pages 部署

[GitHub Pages](https://pages.github.com/) 是 GitHub 提供的免費靜態網站託管服務。優點是完全免費、無限流量、和 GitHub 無縫整合。

使用方法巨簡單，在 GitHub 建立倉庫並上傳網站檔案後，直接在倉庫設定中啟用 GitHub Pages：

![](https://pic.yupi.icu/1/image-20260109111917547.png)

然後就能透過 `username.github.io/repo-name` 訪問了。適合個人主頁、專案文件、簡單的靜態網站。

GitHub Pages 的限制是只能部署靜態網站，不能執行後端程式碼。但對於純前端專案來說，完全夠用了。而且完全免費，不用擔心流量限制。



## 五、雲伺服器部署

如果你想要更多的控制權，可以租一臺雲伺服器，自己部署專案。國內主流的雲服務商有阿里雲、騰訊雲、華為雲等。

雲伺服器部署的基本流程：

1）購買雲伺服器（推薦 2 核 4G 配置起步，第一次購買有新使用者優惠）

2）安裝執行環境，比如 Node.js、Nginx、MySQL 資料庫等

3）上傳程式碼到伺服器

4）配置 Nginx 反向代理

5）配置域名和 SSL 證書

這個過程對於純新手來說會有點兒複雜，但可以使用寶塔面板或 1Panel 這樣的視覺化管理工具，大大簡化操作。這些面板提供了圖形化介面，不需要記複雜的命令，點點滑鼠就能完成配置。

![](https://pic.yupi.icu/1/1736821032080-4be9c9e5-6dfe-434b-8db8-7eb8d7068a16.png)

雲伺服器部署的優點是你有完全的控制權，可以隨時調整配置，而且更穩定。缺點是需要一定的程式設計或運維知識，而且伺服器需要付費（一般每月幾十到幾百元不等）。

## 六、Docker 容器化部署

對於包含前端和後端的全棧專案，Docker 是一個很好的部署方式。Docker 可以把你的應用和執行環境打包成一個容器，在任何支援 Docker 的伺服器上都能執行。

Docker 的優點是環境一致性好，不會出現 “在我電腦上能跑，在伺服器上跑不了” 的問題。而且可以很方便地管理多個應用，每個應用獨立執行，互不影響。

使用 Docker 部署的基本流程：

1. 編寫 Dockerfile，定義應用的執行環境
2. 構建 Docker 映象
3. 執行 Docker 容器
4. 配置 Nginx 反向代理（如果需要）

這個過程相對複雜一些，但可以讓 AI 幫你完成。你只需要告訴 AI：“幫我寫一個 Dockerfile，用來部署這個 Node.js 專案。” AI 會生成完整的 Dockerfile 和部署指令碼。

如果你想學習企業級的部署方式，建議深入學習 Docker。

## 七、AI Agent 應用的部署

除了傳統的前端網站和全棧應用，現在越來越多人開始開發 AI Agent 應用。比如 AI 客服、AI 分析助手、AI 寫作工具這些能跟使用者多輪對話的智慧應用。

這類應用的部署跟普通網站不太一樣，因為它背後需要一整套「AI 基礎設施」的支撐：

- 大模型 API 的對接和金鑰管理
- 多使用者的對話記憶隔離（你不能讓 A 使用者看到 B 使用者跟 AI 聊了什麼）
- 聯網搜尋、檔案解析等工具能力的接入

如果這些都要自己從頭搭建，模型閘道器、對話儲存、工具管理每一項都是不小的工作量，還沒開始寫業務邏輯就累得夠嗆了。

目前比較推薦的方式是使用 **AI Agent 託管平臺**，比如騰訊雲的 [EdgeOne Makers](https://pages.edgeone.ai/zh/document/product-introduction)。這類平臺把模型閘道器、對話記憶、聯網搜尋、鏈路追蹤等能力都幫你準備好了，你只需要專注寫 Agent 的業務邏輯，其他的交給平臺處理就行。

![](https://pic.yupi.icu/1/image-20260629150206869.png)

平臺預設幫你對接了主流大模型，提供一定免費的 Token 額度，支援一鍵切換 DeepSeek、GPT、Claude 等不同模型。而且內建了很多現成的 Agent 應用模板，覆蓋 OpenAI SDK、Claude SDK、LangGraph、CrewAI 等主流框架，JS 和 Python 都能用，選個模板就能快速起步。

![](https://pic.yupi.icu/1/image-20260629150435803.png)



### 部署方式

使用 EdgeOne Makers 部署 AI Agent 有兩種方式。

## 八、CDN 加速最佳化（可選）

部署完成後，如果你想讓網站訪問速度更快，還可以使用 CDN 加速。

CDN（內容分發網路）就是把你的網站內容快取到全球各地的伺服器上，使用者訪問時會自動選擇離他最近的伺服器，大大提高載入速度。

![](https://pic.yupi.icu/1/1763643073516-5248d56c-bf7d-4537-b8f8-681a104626d9.png)

[Cloudflare](https://www.cloudflare.com/zh-cn/) 提供免費的 CDN 服務，優勢是：

- 完全免費（個人網站）
- 全球 CDN 加速，覆蓋 200+ 個城市
- 自動 HTTPS 證書
- DDoS 防護和 Web 防火牆
- 免費的 DNS 服務

使用方法很簡單，註冊 Cloudflare 賬號，新增你的域名，然後把域名的 DNS 伺服器改成 Cloudflare 提供的地址就行。Cloudflare 會自動幫你加速和保護網站。

也可以直接使用 Cloudflare 提供的 Pages 頁面部署能力，直接上傳自己的程式碼，交給它一鍵部署並白票免費的域名，更方便~

![](https://pic.yupi.icu/1/1763643412558-4d499b46-5e16-4f83-9df7-06a85175df35.png)

如果你的網站部署在 Vercel 或 Netlify 上，它們本身就有 CDN 加速，不需要額外配置 Cloudflare。但如果你是自己租伺服器部署，強烈建議用 Cloudflare 加速。



## 九、域名和 SSL 證書

部署完成後，你可能想給網站配置一個好記的域名，而不是一直用難以記憶的 IP 地址讓使用者訪問。



### 購買域名

域名就是網站的地址，比如 [codefather.cn](https://codefather.cn/)、[dogyupi.com](http://dogyupi.com/)。對於國內使用者，我推薦在 [阿里雲](https://wanwang.aliyun.com/) 或 [騰訊雲](https://dnspod.cloud.tencent.com/) 這種知名雲服務商購買域名。價格一般是幾十塊錢一年，而且操作介面都是中文的，很方便。

需要注意的是，如果你的網站伺服器在國內，域名需要備案。備案流程大概需要 1 ~ 2 周，需要提供身份證、手機號等資訊。如果你的網站部署在 Vercel、Netlify 這些國外平臺上，或者在國外平臺購買域名，那麼可以省去備案，快速上線。



### 配置 SSL 證書

現在的網站基本都要求 HTTPS，所以需要配置 SSL 證書。好訊息是，大部分部署平臺都會自動配置 SSL 證書，你不需要手動操作。

比如 Vercel、Netlify、GitHub Pages、EdgeOne Pages 都會自動配置 HTTPS，你只需要繫結域名就行。

如果你是自己租伺服器部署，可以使用免費的 [Let's Encrypt](https://letsencrypt.org/zh-cn/) 證書，或者用 Cloudflare 的 CDN，它們都會自動配置 HTTPS。
