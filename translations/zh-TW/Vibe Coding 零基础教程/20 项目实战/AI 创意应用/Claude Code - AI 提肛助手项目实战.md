# Claude Code - AI 提肛助手專案實戰

本專案是一個 AI 驅動的提肛運動助手網站，提供科學的分級訓練課程、動畫引導、語音播報，還支援攝像頭姿態檢測和 AI 糾正建議。全程使用 Claude Code + DeepSeek V4 開發。

大家好，我是程式設計師魚皮。

唉，久坐不動可以說是程式設計師的通病。像我天天忙的要死，根本沒時間運動，但又不甘心讓身體就這樣退化，怎麼辦呢？

於是，我透過詢問 AI，瞭解到了「提肛運動」。透過增強盆底肌肉力量、促進區域性血液迴圈，有效預防痔瘡、改善大小便失禁，並提升肛門及相關盆腔器官的健康功能。

關鍵是這玩意隨時隨地都能做，太適合我了！

![](https://pic.yupi.icu/1/ybzj.jpg)

但我自己是個「運動白痴」，所以想到能不能透過 AI 程式設計，開發個「提肛助手」，幫助大家科學地進行盆底肌訓練，傻子也能練對。

安排！

下面我將全程用 Claude Code + DeepSeek V4 來開發一個完整專案，從安裝配置到開發測試，手把手帶你走一遍。看完這篇，你能學會 Claude Code 的保姆級使用方法，感受 DeepSeek V4 的實際程式設計能力，還能 get 到不少 AI 程式設計的實用技巧。

點個收藏，咱們開始~



## 需求分析

這個專案叫「提肛助手」tgang-helper，核心功能其實不復雜。

1）提供科學的分級訓練課程，區分男女和難度，涵蓋快速收縮、持續收縮、階梯收縮等多種動作型別。

2）訓練過程中要有動畫引導節奏，包括呼吸圈動畫和人體姿勢示範動畫，讓使用者一看就知道該怎麼做。

3）同時透過瀏覽器語音合成實時播報指令，讓使用者閉著眼睛也能跟練。

4）還有一個亮點功能，就是支援開啟攝像頭進行體位校正。實時檢測你的站姿、坐姿是否正確，比如有沒有駝背、聳肩、身體歪斜，當檢測到姿勢問題時，讓 AI 提供個性化的糾正建議。

5）檢視訓練打卡日曆和統計圖表。

![](https://pic.yupi.icu/1/image-20260429104714827.png)



## 方案設計

如果你完全沒有任何技術基礎，可以讓 AI 幫你完成方案設計。

但這裡為了節省時間和 tokens，我直接告訴 AI 怎麼做。

雖然要做姿態檢測功能，但是這個專案幾乎是 **純前端** 就能搞定！不需要複雜的後端。

技術棧上，我選擇 Next.js + TypeScript，姿態檢測用 MediaPipe Pose（純前端執行），AI 對話透過 Next.js 的 API Route 代理呼叫 DeepSeek V4 模型，動畫用 CSS 動畫 + Framer Motion。

為什麼不用 Python 後端？

因為這個專案唯一需要服務端的地方就是代理一下 AI 介面呼叫，使用 Next.js 的 API Route 完全能搞定，沒必要拆成前後端分離，越簡單越好。

![](https://pic.yupi.icu/1/tgang-helper-design.jpg)



## 環境準備

### 安裝 Claude Code

先簡單介紹一下 Claude Code。它是 Anthropic 推出的 AI 程式設計工具，直接在終端裡執行，你跟它聊天描述需求，它就能自主分析專案、寫程式碼、跑命令、修 Bug，全程自主執行。

除了基礎的程式碼生成，還能使用工具和 Skills 技能包、連線 MCP 外部服務、用 Plugins 外掛擴充套件能力，甚至搞多智慧體協作，擴充套件性很強。

![](https://pic.yupi.icu/1/image-20260429110454017.png)

安裝 Claude Code 很簡單。

首先確保你的電腦有 Node.js 環境和 npm 軟體依賴安裝工具，沒有的話，直接到 [Node 官網](https://nodejs.org/en/download) 下載傻瓜式安裝包就好：

![](https://pic.yupi.icu/1/1777341714221-67b76f0e-c816-410b-adc0-e445074efc46.png)

無論使用什麼作業系統，都可以透過 npm，一行命令來安裝 Claude Code：

```bash
npm install -g @anthropic-ai/claude-code
```

![](https://pic.yupi.icu/1/1777341807032-be0f1d99-4e97-4be6-80de-de7c32846d41.png)

安裝完成後，輸入 `claude` 命令進入對話介面，首次需要登入才能正常使用：

### 安裝擴充套件

Claude Code 預設就有讀寫檔案、跑終端命令、搜尋程式碼這些基礎能力，但要做好一個完整專案，光靠這些還不夠。

我們需要下面 3 個擴充套件：

1. Frontend Design：前端美化技能，讓生成的頁面更有設計感
2. Firecrawl：聯網搜尋和網頁抓取，讓 AI 能獲取最新的技術資訊
3. Context7：查詢最新的技術文件和 API 用法，減少 AI 瞎編的情況

下面來依次安裝。



#### 1、安裝 Frontend Design

Frontend Design 是 Anthropic 官方的前端美化技能，可以讓 AI 生成的頁面更有設計感。

在 Claude Code 中，先透過 `/plugin` 命令新增官方技能市場，相當於裝了個技能商店：

```bash
/plugin marketplace add anthropics/skills
```

![](https://pic.yupi.icu/1/1777344066799-72c95f99-82bc-46ff-92f5-02cf6d21b1b9-20260429113524910.png)

輸入 `/plugins`，在 Discover 選單欄中，選中 `example-skills` 並按回車，安裝官方的示例技能合集：

![](https://pic.yupi.icu/1/1777344221815-19f8cc7d-e608-4cf6-a8a9-05fa3dafab04.png)

輸入 `/reload-plugins` 過載一下外掛：

![](https://pic.yupi.icu/1/1777344303461-6af1d179-4328-4892-83b4-a48f1af3c32d.png)

輸入 `/skills` 檢視已安裝的技能，可以看到 `frontend-design` 已經就位了：

![](https://pic.yupi.icu/1/1777344408094-9d8e06b5-a216-443e-a7ec-70dd78cb80d0.png)

之後在對話方塊中輸入 `/frontend-design` 就能主動觸發這個技能，讓 AI 美化前端頁面。同時還自動裝上了 `webapp-testing` 自動化測試技能，後面也用得上。



#### 2、安裝 Firecrawl

Firecrawl 是聯網搜尋和網頁抓取工具，讓 AI 開發前先搜尋最新技術資訊。

## 開發編碼

新建一個 `tgang-helper` 專案資料夾，在終端中用 `cd` 進入該目錄，然後輸入 `claude` 命令開啟 Claude Code：

![](https://pic.yupi.icu/1/1777346556569-10234894-8a0e-4efe-98cb-a9d14b122279.png)

然後輸入提示詞。這裡分享一下我實際用的完整提示詞，給大家參考：

```markdown
## 角色

你是一個前端全棧工程師，擅長 Next.js + TypeScript 開發。

## 任務

開發一個叫 tgang-helper 提肛助手的 Web 應用，幫助使用者科學地練習盆底肌訓練（提肛 / 凱格爾運動），傻子也能練對。

提供科學的分級訓練課程，區分男女和難度，涵蓋快速收縮、持續收縮、階梯收縮等多種動作型別。訓練過程中透過動畫引導節奏，包括呼吸圈動畫（收縮時縮小、放鬆時擴大）和人體姿勢示範動畫（用 SVG 或 Lottie 展示每個動作的正確體位和發力部位），讓使用者一看就知道該怎麼做。同時使用瀏覽器語音合成（Web Speech API）實時播報指令，讓使用者閉著眼睛也能跟練。

支援開啟攝像頭進行體位校正，使用 MediaPipe Pose 在瀏覽器端實時檢測使用者的站姿 / 坐姿是否正確（如駝背、聳肩、身體歪斜），所有檢測純本地執行，攝像頭畫面不上傳伺服器。當檢測到持續的姿勢問題時，將姿勢資料（非影象）傳送給 DeepSeek V4 模型，獲取個性化的糾正建議並語音播報。

訓練記錄儲存在本地 localStorage，展示打卡日曆和簡單的統計圖表。

## 技術棧

- 框架：Next.js + TypeScript
- 姿態檢測：MediaPipe Pose（純前端）
- AI 對話：透過 Next.js API Route 代理呼叫 DeepSeek V4 模型（相容 OpenAI SDK 格式）
- 動畫：CSS 動畫 + Framer Motion

## 要求

1. 頁面美觀專業，使用 frontend-design 技能美化頁面，配色健康積極
2. 開發前，先透過 Firecrawl 聯網搜尋 MediaPipe Pose 瀏覽器端用法，透過 Context7 查詢最新技術文件和用法
3. 必須生成完整可執行的程式碼，每步完成後必須自主測試驗證
```

簡單解讀一下這段提示詞的幾個要點：

- **角色定義** 放在最前面，讓 AI 進入前端全棧工程師的狀態
- **任務描述** 用自然語言把需求講清楚
- **技術棧** 只列關鍵選型，讓 AI 自己決定實現細節
- 最後兩條要求是關鍵，讓 AI 先查文件再寫程式碼，避免瞎編寫法；讓 AI 開發完後自主測試，減少翻車

幫我建立 .env.local 檔案

說實話，一段提示詞就讓 AI 一把梭出了整個專案，核心功能基本可用，DeepSeek V4 的效果還是不錯的。

不過實際跑起來還是有一些小 Bug，比如呼吸動畫的收緊放鬆節奏跟實際訓練動作對不上，快速收縮模式下動畫一直顯示「收緊」不切換到「放鬆」，還有 AI 姿態建議的呼叫時機沒控制好，導致頻繁請求。

這裡分享一個我自己的經驗。測試的時候，影響核心功能的問題要立刻修復，比如動畫節奏不對這種，直接跟 AI 描述現象讓它改。

不影響核心功能的問題，比如只是覺得介面某個地方不夠好看，建議先記下來，等核心流程跑通之後再集中處理。

另外，過程中一定要隨時關注上下文的容量。我修完這幾輪 Bug 後，上下文已經漲到了 62%：

![](https://pic.yupi.icu/1/1777358465249-dbc18a92-6c77-471d-a15e-4f79a7837a67-20260429113526400.png)

上下文一旦快滿了，AI 就可能忘記之前改過什麼，甚至寫出跟之前矛盾的程式碼。

遇到這種情況，建議先讓 AI 把當前專案資訊和進度沉澱成文件（比如寫進 CLAUDE.md），然後開一個新會話繼續開發，既節省 tokens 又不會丟失重要上下文。



## 我的感受

最後聊聊這次 Claude Code + DeepSeek V4 實戰做專案的真實感受。

先說說 DeepSeek V4 的實際表現。**一段提示詞一把梭出完整專案 + 核心功能可用**，彷彿讓我感受到了曾經 Opus 帶給我的驚喜。

前端雖然沒什麼特別驚豔的創新，但佈局基本正確，配色也不拉胯。不過前面也提到了，在邏輯細節上還是有些不足，需要人工介入幾輪才能調好。而且 DeepSeek V4 在程式碼生成速度上略慢一些，31 分鐘才跑完核心功能。

除了效果外，再看看大家關注的 **成本**。

做完這個專案，到底花了多少錢呢？

我一看，幾百次請求，竟然消耗了 2500 多萬 tokens！

![](https://pic.yupi.icu/1/1777359821224-7aa241e7-c2a3-4740-8808-289422131b76.png)

![](https://pic.yupi.icu/1/1777359775291-dca79c0d-6053-4721-ab50-6a2bb2895d04.png)

這麼多 tokens 裡絕大部分是輸入快取命中的。因為 Claude Code 每次跟模型對話時，會把之前的上下文一起發過去，但如果內容跟上次一樣，DeepSeek 會命中快取，快取價格只有正常輸入的幾分之一。

這就是為什麼雖然 tokens 用量看起來很嚇人，但實際花費很低。
