## 環境準備

智譜的 GLM-4.7 相容多款編碼工具，除 Claude Code 外，還支援 Cursor、Cline 等主流編碼工具，靈活適配多種開發場景。

給 Claude Code 接入 GLM 也很簡單，1 分鐘搞定。

首先開啟終端，輸入一行命令安裝 Claude Code：

```shell
npm install -g @anthropic-ai/claude-code
```



然後執行 `claude` 命令開啟程式，預設是需要登入 Claude 賬號的，否則無法使用：

![](https://pic.yupi.icu/1/1764145940075-ace6fd24-a09c-41c0-b400-1cffc394fc8a.png)



不過沒關係，讓我們把它背後的 AI 大模型換成國內的 GLM-4.7。首先進入 `{使用者目錄}/.claude` 目錄，建立一個 `settings.json` 配置檔案： 

![](https://pic.yupi.icu/1/1764146110361-06e13de5-7de4-4fc5-9533-3651447d5e19.png)



然後修改配置檔案中的內容如下，記得替換成你自己的 API Key：

![](https://pic.yupi.icu/1/1764146125955-3029843c-26b8-4628-b2b7-a9d8abb2aef1.png)



API Key 直接到智譜開發平臺獲取即可：

接下來就可以愉快地使用了~

## 技術調研

如果要完全利用 AI 開發專案，有幾個難點：

1. 專案需要包含完整前後端，需要大模型有較強的 **編碼能力**
2. 需要讓後端專案對接 AI 大模型，每個大模型的接入和開發方式不同，需要讓 AI **讀取文件** 理解最新的開發方式
3. 如果想要最佳化介面效果，還需要 **圖片理解能力**，給 AI 一張圖片就能讓它還原

在正式開發前，我們要確認 GLM-4.7 和 Claude Code 的配合能夠滿足這些能力要求。

根據智譜官方介紹，Claude Code 中內建了智譜專屬的 MCP 工具，不需要開發者自己安裝。包括 **搜尋和網頁讀取** 能力、能夠直接解析截圖/設計稿/報錯圖的 **視覺理解能力**。

讓我們依次測試一下，首先是網頁搜尋能力，緊跟時事：

![](https://pic.yupi.icu/1/1766541771159-00bcb3ee-422b-4895-9ab6-15e5ad44937e.png)

測試網頁讀取能力，讓它來讀取我們程式設計導航網站的資訊：

![](https://pic.yupi.icu/1/1766485091937-8555eddf-7301-4161-92d9-4f19251cf9d1.png)

測試圖片理解能力，我給 AI 傳了一張 “從夯到拉排行榜的背景圖”：

![](https://pic.yupi.icu/1/1766552716828-cc3c5015-a220-44c4-9c99-9ea6e6cc9a2e.png)

AI 的理解還是很準確的，具體文字也讀取出來了。

OK，幾個能力都滿足要求，下面讓我們進入方案設計和開發階段。
