# GitHub Copilot - AI 闖關學習小程式專案實戰

這是一套以 AI 程式設計實戰為核心的專案教程，基於 Taro + Python FastAPI + LangChain + LangGraph + DeepSeek，用 AI 程式設計的方式從 0 到 1 開發一個《AI 闖關學習微信小程式》，並且走完部署上線的全流程，帶你親身體驗 AI Vibe Coding 的完整工作流，學會用 AI 做出一個能上線、能傳播、能變現的小程式產品！

專案程式碼免費開源：https://github.com/liyupi/yu-ai-learn

完整影片教程 + 文字教程（預計 3 ~ 7 天學完）：https://www.codefather.cn/course/2037104890135748610

![](https://pic.yupi.icu/1/1-project-demo-overview.png)



## 專案介紹

學知識這件事，最大的敵人就是枯燥。看文件、看影片，看著看著就走神了，看完還是記不住。

而人天生喜歡玩遊戲，喜歡闖關、答題、拿獎勵。既然現在有了 AI，為什麼不讓 AI 把「我想學的任何知識」自動變成一局闖關遊戲呢？

這就是這個專案的起點：使用者輸入一句話，說出自己想學什麼，AI 自動聯網搜尋最新資料並生成一組闖關題目，使用者邊答邊學，每答一題立刻給出答案和講解，通關後還能拿到一份 AI 覆盤報告。

為什麼做成微信小程式，而不是 App 或者網頁？因為使用者經常在碎片時間裡學習小知識，微信小程式免安裝、隨時隨地能開啟、依託微信生態的流量入口、還便於分享給朋友一起卷，對一個學習類產品來說幾乎是最優形態。

更重要的是，這個專案的骨架可以直接複用到任何垂直領域，換個知識源就是一個新產品，比如駕考寶典、面試題庫、企業內部培訓考核、職業資格考試複習、英語單詞闖關等等。

![](https://pic.yupi.icu/1/2-driving-theory-quiz-flow.png)



## 專案功能演示

1）輸入想學的知識，AI 自動出題

在首頁的輸入框裡，用一句話或者一段話描述你想學什麼，選擇題目難度和數量，點選「開始生成題目」，AI 就會自動去聯網搜尋相關資料，然後生成一組包含單選、多選、判斷三種題型的闖關題目。

![](https://pic.yupi.icu/1/3-vibecoding-web-search-and-correct-answer.png)



2）闖關答題，答完立刻講解

題目生成後進入闖關頁面，頂部有進度條和金幣數，每答完一題立刻告訴你對錯，並給出這道題的答案解析和對應的知識點，邊玩邊學。

![](https://pic.yupi.icu/1/4-vibecoding-wrong-answer-and-submit.png)



3）AI 生成通關覆盤報告

一組題目答完後，AI 會基於你的答題情況生成一份覆盤報告，包含掌握度評分、答錯的薄弱知識點、知識總結和下一步學習建議，還會結算本局獲得的經驗值。

![](https://pic.yupi.icu/1/5-vibecoding-report-and-question-review.png)



4）AI 聯網搜尋，出的題不過時

大模型的知識有截止日期，如果直接讓它出題，很容易出一些過時甚至錯誤的題目。所以專案給出題環節接入了聯網搜尋，讓 AI 先自主判斷要不要搜、搜什麼關鍵詞，拿到最新資料後再出題。

這一步本質上是把「出題」從一次簡單的大模型呼叫，升級成了一個會自己上網查資料的 AI Agent。而且做了完整的降級策略，搜尋不可用時會自動退回用大模型自身的知識出題，不影響主流程。

![](https://pic.yupi.icu/1/6-yupi-ai-nav-search-and-quiz.png)



5）上傳自己的知識庫，基於私有文件出題

在「我的」頁面可以進入知識庫，上傳 PDF、Word、Markdown、TXT 格式的文件。系統會自動把文件切成小塊、轉成向量存進向量資料庫，之後就能選擇某篇文件來出題，題目完全來自你上傳的私有資料。

這個能力讓專案從「學公開知識」擴充套件到了「考自己的資料」，可以用來做企業內部培訓考核、特定題庫複習、考試衝刺等場景。

![](https://pic.yupi.icu/1/7-knowledge-base-upload-and-quiz.png)



6）AI 給題目配圖，學得更直觀

生成題目時可以勾選「生成配圖」，AI 會根據每道題的知識點生成一張配圖。比如刷英語單詞時，「蘋果的英文是什麼」這道題會配上一張蘋果的圖片，學習體驗直觀有趣得多。

生成的圖片會自動轉存到物件儲存，拿到永久訪問連結，避免 AI 生圖介面返回的臨時連結過期後圖片失效。同時還做了每日額度限制和多題併發控制，兼顧體驗和成本。

![](https://pic.yupi.icu/1/8-ai-generated-illustration-quiz.png)



7）微信一鍵登入，闖關記錄隨時回看

小程式採用微信靜默登入，使用者無感授權即可擁有賬號，闖關記錄、經驗值、答題歷史全部持久化儲存。在「我的」頁面可以檢視累計經驗值和歷史闖關列表，點進任意一條還能回看當時的覆盤報告。

同時專案做了「可選登入」的設計，沒登入也能體驗出題和答題，只是不儲存記錄，最大程度降低了新使用者的使用門檻。

![](https://pic.yupi.icu/1/9-profile-and-history.png)



8）真正上線，微信裡搜得到

這個專案不是做完就丟在本地，教程會帶你把後端 Docker 化部署到容器託管平臺、把本地 MySQL 換成雲資料庫、走完一套小程式釋出流程，讓任何人都能在微信裡搜到並使用你做的小程式。

![](https://pic.yupi.icu/1/image-20260811183313570.png)



## 功能梳理

該專案功能豐富，涵蓋闖關答題、AI 出題、覆盤報告、使用者系統、知識庫、AI 配圖 6 大模組，30+ 功能點，覆蓋了一個真實上線小程式的核心業務場景。

![](https://pic.yupi.icu/1/image-20260811155000927.png)

闖關答題模組：

- 自由輸入想學的知識（一句話或一段話）
- 難度自選（簡單 / 中等 / 困難 / 混合）
- 題量自選（3 到 10 題）
- 單選、多選、判斷三種題型
- 答完即時判分，展示正確答案
- 每題給出解析和對應知識點
- 關卡進度、答對數、金幣展示

AI 出題模組：

- DeepSeek 大模型生成題目
- Tavily 聯網搜尋補充最新知識
- 搜尋 Agent 自主決定檢索內容
- 提示詞約束大模型輸出結構化 JSON
- 題目結構解析和欄位校驗
- 非同步任務建立與狀態流轉
- 前端輪詢獲取出題進度
- 搜尋不可用時自動降級

覆盤報告模組：

- AI 生成通關覆盤報告
- 掌握度評分和進度條展示
- 薄弱知識點定位
- 三句話知識總結
- 下一步學習建議
- 分享文案生成
- 經驗值獎勵結算

使用者系統模組：

- 微信靜默登入（換取 openid）
- JWT 令牌簽發與校驗
- 可選登入模式（未登入也能體驗）
- 個人中心（暱稱、頭像、經驗值）
- 修改個人資料
- 闖關歷史列表（分頁）
- 闖關詳情回看

知識庫模組：

- 上傳 PDF、Word、Markdown、TXT 文件
- 文件解析並切分成文字塊
- 文字塊向量化後寫入向量資料庫
- 按使用者隔離的向量集合
- 文件解析狀態輪詢
- 文件列表和刪除
- 文件數量和單檔案大小配額
- 基於指定文件做 RAG 出題

AI 配圖模組：

- 按題目知識點構建配圖提示詞
- 呼叫生圖模型生成題目配圖
- 圖片轉存物件儲存獲取永久連結
- 多題併發生圖（訊號量控制）
- 每日生圖額度限制
- 生圖失敗不影響出題主流程

## AI 程式設計開發流程

這個專案遵循最主流的 AI 程式設計專案開發流程，使用 GitHub Copilot 作為主力 AI 程式設計工具，搭配 Claude Code 做 UI 原型設計，並透過 OpenSpec 規範驅動開發來管理長週期專案。

第一步，需求分析。先人工做需求分析，明確目標使用者、核心痛點和 MVP 邊界，再用 Gemini Deep Research 做 AI 需求調研和競品分析，兩者交叉驗證後確認需求文件。

第二步，方案設計。讓 AI 輔助技術選型，人工稽核並修正後確定技術棧（Taro + FastAPI + LangChain），設計出題提示詞和結構化輸出格式，生成方案設計文件。

第三步，UI 原型。讓 Claude Code 和 GitHub Copilot「賽馬」，同時產出兩套 HTML 原型，結合兩套方案的優勢深度最佳化，確定 UI 風格和設計系統，作為後續開發的視覺基準。

第四步，核心功能開發。編寫開發提示詞讓 AI 生成前後端程式碼，接入 DeepSeek 大模型實現 AI 出題，跑通「輸入 → 出題 → 答題 → 報告」核心業務流程。

第五步，持續迭代。逐步完成使用者系統、聯網搜尋 Agent、RAG 知識庫、AI 生圖等功能模組，每做完一個功能就用 Git 提交程式碼，上下文太長時新開對話視窗，用 OpenSpec 歸檔文件讓 AI 找回記憶。

第六步，部署上線。Docker 容器化部署到微信雲託管，走完小程式釋出全流程。

## 核心業務流程

### 使用者使用流程

整個使用流程非常簡單：開啟小程式 → 輸入想學的知識 → 等 AI 出題 → 答題闖關 → 看覆盤報告，幾分鐘完成一次學習閉環。

![](https://pic.yupi.icu/1/01_%E7%94%A8%E6%88%B7%E4%BD%BF%E7%94%A8%E6%B5%81%E7%A8%8B_compressed_v1.png)



### AI 非同步出題流程

AI 出題要先聯網搜尋再讓大模型推理，整體耗時可能達到幾十秒，而微信小程式的單次請求有超時限制。所以出題介面不直接等結果，而是建立一個後臺任務立刻返回任務 ID，由前端輪詢獲取進度。

![](https://pic.yupi.icu/1/02_AI%E5%BC%82%E6%AD%A5%E5%87%BA%E9%A2%98%E6%B5%81%E7%A8%8B_compressed_v2.png)

搜尋或生圖環節出現異常時，都不會讓整個任務失敗。搜尋失敗就退回用大模型自身知識出題，生圖失敗就出沒有配圖的題目，保證核心鏈路始終可用。



### 知識庫 RAG 出題流程

上傳文件後，系統會在後臺完成解析、分塊、向量化，之後就能基於這篇文件出題。檢索環節用的是 Agentic RAG，由 AI 自己決定檢索什麼、檢索幾次。

![](https://pic.yupi.icu/1/03_%E7%9F%A5%E8%AF%86%E5%BA%93RAG%E5%87%BA%E9%A2%98%E6%B5%81%E7%A8%8B_compressed_v1.png)



## 技術選型

本專案以 Taro 微信小程式 + Python FastAPI + LangChain / LangGraph 為核心，前後端分離，綜合運用了多種主流的小程式開發和 AI 應用開發技術。

![](https://pic.yupi.icu/1/image-20260811155041400.png)

小程式前端：Taro 4 跨端框架、React 18 + Hooks、TypeScript、Sass、Taro.request 統一請求封裝、微信開發者工具

後端：Python 3.11+、FastAPI Web 框架、Pydantic v2 資料校驗、Uvicorn ASGI 伺服器、asyncio 非同步後臺任務、aiomysql 非同步連線池、PyJWT 登入令牌、pytest 測試

AI 相關：LangChain AI 應用開發框架、LangGraph ReAct Agent、Tavily 聯網搜尋 API、Chroma 向量資料庫、DeepSeek 大模型、阿里雲百鍊 Embedding 模型、通義千問生圖模型、結構化輸出（提示詞約束 + JSON 解析 + 模型校驗）

資料和儲存：MySQL 8、Chroma 本地持久化、騰訊雲 COS 物件儲存、微信 code2Session 介面、JWT 無狀態登入態

部署上線：微信雲託管 Docker 容器託管、雲資料庫 MySQL、小程式服務類目申請、ICP 備案、程式碼稽核與釋出上線

AI 程式設計工具：GitHub Copilot 主力 AI 程式設計工具（含免費方案）、Claude Code 命令列 AI 程式設計工具、OpenSpec 規範驅動開發、MCP 外掛（Firecrawl 聯網搜尋、Context7 最新技術文件、Playwright 瀏覽器自動化）、Agent Skills（前端設計、圖片理解）、Harness Engineering、Gemini Deep Research



## 架構設計

本專案採用前後端分離架構。前端是 Taro 編譯的微信小程式，後端是 FastAPI 服務，透過 HTTPS 介面通訊。

後端內部按照路由層、業務服務層、資料訪問層分層，耗時的 AI 任務透過程序內非同步任務加資料庫狀態表來管理，前端輪詢獲取結果。

檢索增強、AI 配圖等能力對接了多家外部服務，資料分別落在關係型資料庫、向量資料庫和物件儲存中。
